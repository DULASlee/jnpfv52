# 任务启动模板（开新 Chat 首条粘贴）

> **先 @：** [`.cursor/CURRENT-FOCUS.md`](../CURRENT-FOCUS.md)  
> **给人看：** [`how-to-brief-agents.md`](./how-to-brief-agents.md)

---

【指挥原则】
机器验收 + 人只看演示。一个 Chat = 一件可演示的事。跑偏 → 建议重开，别长文纠偏。
底仓不废：ADF / claim / L11–L12 / 铁律仍由机器硬拦。

【老板模式 + 人话汇报】
用户只回：`继续` / `通过` / `打回` / `重开`。
禁止：长差距表、决策摘要、A/B、「是否授权」、**正文堆类名/方法名/文件:行号**。
对人只说业务结果；符号名只写进 CR 或证据附录。自检：去掉符号名后老板是否看得懂。
默认：343 只读抽样；⑤⑥⑦⑧ 并入 T9；能修就修；ADF P1–P3 一次交齐 → 一句「继续」进 P4。
才准问人：改生产数据 / 进下一 SG / 需 CR / 真卡住需人唯一动作。

【完成定义】
「完成」= 业务可用，不是测试绿。以 `@CURRENT-FOCUS.md` 为准。

【本 Chat 目标 — 只填一件】
（一句可演示结果，例：343 的 02 能证明走过 PM 三轮澄清。空则 Agent 自取当前最大缺口一件。）

【对照】
阶段 A-B-C（`1、阶段A/B/C.md`）；旧 25–33 已废止归档，禁止整本灌入。

【非目标】
只修测试、假实现、让人审报告、一个 Chat 塞整阶段。

【分级】S（除非 CURRENT-FOCUS 另写）；窄 bug 可用 B + `adfPhase=exempt`。

【ADF】自设 phase；P1–P3 一次交齐 → 「继续」→ P4。禁止逐步逼问。

【可审批】claim + `pillar-claim-check.mjs --force` → 交「可审批」。

【输出 — 每条只选一种，≤10 行 · 必须人话】
```text
【状态】已修好 / 卡住 / 等你批改法说明 / 建议重开
【人话】发生了什么 + 现在怎样 + 你点头后我会怎样（无类名）
【你怎么验】命令一行 + 打开哪个文件/页面
【要你做】继续 | 通过 | 打回 | 重开
（可选）详情：CR-….md
```
禁止复述目标/贴大表/用工程师黑话当正文。
