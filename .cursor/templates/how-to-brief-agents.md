# 如何向 Agent 简报（防假绿 · 防把人累死 · 给人用）

> **目的：** 业务真绿 + **你不当项目经理**。机器验收，人只看演示。  
> **当前焦点：** [`../CURRENT-FOCUS.md`](../CURRENT-FOCUS.md)  
> **配套：** [`task-kickoff.md`](./task-kickoff.md) · [`four-pillars-checkpoint.md`](./four-pillars-checkpoint.md)  
> **底仓：** ADF / 四支柱 / hooks / 铁律 **保留**——改的是「人怎么用」，不是废掉硬门。

---

## 0. 指挥原则（2026 微调）

| 原则 | 你做什么 | Agent 做什么 |
|---|---|---|
| 机器验收 | 跑他给的命令、开产物路径 | 交付物必须带验收命令 + 路径 |
| **人话汇报** | 看不懂就回「用人话重说」 | 正文零类名/方法名；细节进 CR |
| 一 Chat 一事 | 目标写一句可演示结果 | 禁止整阶段塞进一轮 |
| 跑偏就重开 | 回 `重开`，新 Chat @ CURRENT-FOCUS | 旧对话别长文纠偏 |
| 底仓不废 | 可审批仍看 claim① | ADF/L11–L12/铁律机器硬拦照旧 |

**口令：`继续` / `通过` / `打回` / `重开` /（可选）`用人话重说`。**

### 人话自检（Agent 发出前）

去掉所有 `XxxService` / 方法名 / `文件:行号` 后，非程序员是否还懂？不懂 = 违规，重写后再发。

## 1. 老板模式（默认）

| Agent 必须自己做 | 禁止甩给你 |
|---|---|
| 默认决策（⑤⑥⑦⑧ 并入 T9、自动 343 抽样） | A/B、「是否授权」 |
| 自己抓证据、能修就修 | 长差距表、决策摘要 |
| ≤10 行，只交四种交付之一 | 让你审报告再开工 |

**才准问你：** 改生产数据 / 进下一 SG / 需 CR / 真卡住且只要你做一个动作。

开 Chat：

1. `@CURRENT-FOCUS.md` + `@task-kickoff.md`（或 §8.1）。
2. 本 Chat 目标写**一句**可演示结果（可写在 CURRENT-FOCUS「本 Chat 只做」）。
3. 之后只回口令；「可审批」时跑命令 + 瞄产物，不读长文。

---

## 2. 「绿」的定义

以 CURRENT-FOCUS 的 Q1–Q3 / ① 为准。**@ 即可，别每轮复读。**  
原则：验收看产物 + 命令；测试只是辅助。

---

## 3. 话术对照

| 少说 | 正确做法 |
|---|---|
| 你选 A 还是 B？ | （禁止）默认并入 T9 |
| 是否授权抽样？ | （禁止）默认 343 |
| 请审差距表 | （禁止）内部消化；≤10 行交付 |
| 堆类名方法名给你看 | 回 `用人话重说`；细节应在 CR |
| 把测试跑绿 | 交「已修好」+ 验收命令 + 产物路径 |
| 这 Chat 已经糊了还继续骂 | 回 `重开` |

---

## 4. 硬门（机器拦 · 人少参与）

### ADF（老板模式）

```text
Agent 自设 adfPhase；P1–P3 一次交齐
→ 你只回一次「继续」进 P4
→ 禁止逐步问 P2/P3
窄活：B 级 + adfPhase=exempt
```

### 可审批（底仓保留）

```text
claim + pillar-claim-check.mjs --force
交「可审批」时必须附：验收命令 + 产物路径
你：跑命令 → 开文件瞄一眼 → 通过/打回
```

---

## 5. 一票否决（只盯① + 演示）

可审批时只看：

- [ ] ① 是业务能力（非纠偏列表）
- [ ] 验收命令能跑 / 产物路径打得开
- [ ] 不是「N 个测试过了」顶替

```text
打回。业务没通。重做后只交「可审批」或「已修好」（须带验收命令+路径）。
```

---

## 6. 自检

| 你刚说了… | 应改成… |
|---|---|
| 先把测试弄绿 | 业务通 + 验收命令 PASS |
| 怎么还不过（改断言也行） | 修实现，禁改断言凑过 |
| 继续推进整阶段 | 本 Chat 只做一件可演示事；通过后再开下一 Chat |
| 再解释一遍给我听 | `重开` 或 `违规，≤10 行` |

---

## 7. 合理预期

- 你不当审报告的人；只跑命令、看产物、回口令。
- 啰嗦/跑偏 → `重开`，别教育。
- 大佬打法失灵 → 仍可用 claim + ADF 节点审批（底仓），口令不变。

```text

@.cursor/templates/task-kickoff.md

老板模式 + 机器验收。本 Chat 只做一件：【填可演示目标，或让 Agent 自取最大缺口】。

我只回：继续 / 通过 / 打回 / 重开。
每条 ≤10 行：已修好（须验收命令+路径）/ 卡住 / 可审批 / 建议重开。
禁止长表与 A/B。继续干活。
```
