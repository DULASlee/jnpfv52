## ORM Contract Baseline

### Entity Inheritance Hierarchy

```
IdEntityBase<TKey>
└── EntityBase<TKey> (adds TenantId, ZxSystemId)
    └── CLDEntityBase (adds 7 audit/soft-delete fields)
        └── CLDSEntityBase (adds tenant filter capability)
    └── TenantEntityBase<TKey> (tenant-aware base)
        └── TenantCLDSEntityBase (tenant-aware + soft-delete)
```

### Standard Conventions

| Aspect | Convention |
|--------|------------|
| Primary Key | `F_ID` with `[SugarColumn(IsPrimaryKey = true)]` |
| Tenant Filter | `F_TENANT_ID` via `ITenantFilter` |
| Audit Fields | `F_CREATOR_TIME`, `F_CREATOR_USER_ID`, `F_LAST_MODIFY_TIME`, `F_LAST_MODIFY_USER_ID`, `F_DELETE_MARK` |
| Soft Delete | `F_DELETE_MARK = 1` |
