# Evidence Chain

## 概述
Evidence Chain 是一等公民，必须完整可追溯。

## 链路
```
Requirement
    ↓
Design
    ↓
Implementation
    ↓
Tests
    ↓
Verification
    ↓
Evidence
    ↓
Gate
```

## Evidence 类型
| 类型 | 说明 |
|------|------|
| document | 文档 |
| screenshot | 截图 |
| log | 日志 |
| report | 报告 |
| diff | 差异 |
| diagram | 图表 |

## 使用
1. 每个 Phase 必须建立 Evidence
2. Evidence Chain 必须完整
3. 无断链
