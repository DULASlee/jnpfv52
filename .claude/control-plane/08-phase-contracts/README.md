# Phase Contract Registry

## 概述
每个正式 Phase 都有一个独立工程单元。

## 结构
```
08-phase-contracts/
├── README.md (本文件)
├── phase-2-b/
│   ├── PHASE-CONTRACT.md
│   ├── DESIGN-SPEC.md
│   ├── IMPLEMENTATION-PLAN.md
│   ├── TEST-MATRIX.md
│   ├── VERIFICATION.md
│   └── ACCEPTANCE.md
└── ...
```

## 使用
1. 创建 Phase Contract
2. 执行 Phase
3. 完成后签署 ACCEPTANCE.md
