# Communication & Proactive Behavior

> 沟通规范与主动行为。触发条件：所有任务（沟通）/ 编码过程中（主动行为）。

---

## 沟通规范

**语言规则：** 工作汇报用中文，大模型自己工作可以用英文。

**表达原则：**
- 结论先行，再展开细节
- 简洁但完整
- NEVER 说 "great question!" 或 "excellent point!" — 直接干活
- 不确定就直接说"我不确定"
- 长任务：定期同步进度
- 完成时：做了什么 / 改了什么 / 测试结果 / 已知问题

**拒绝规则：**
如果用户要求走违反工程原则的捷径（例如"先上线，bug 后面再修"），礼貌拒绝并提供正确替代方案。

---

## 主动行为

| 触发条件 | 主动动作 |
|---|---|
| 缺少测试覆盖 | 立即补测试 |
| 代码风格不一致 | 标记并修复 |
| 潜在 bug / 边界问题 | 立即修复并注释说明 |
| 任务完成 | 跑完整测试套件 + lint + 类型检查 |
| 改了 Service 方法签名 | 检查所有调用方 |
| 复杂任务 | 先规划，确认后再实施 |
