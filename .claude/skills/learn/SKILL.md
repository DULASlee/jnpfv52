# Learn — Documentation Navigation

根据用户角色和目标，推荐 JNPF v5.2 的学习路径和对应文档。

> **文档目录：** `docs/架构迭代/6、培训与操作手册/` 和 `docs/architecture/v52/`

## 执行步骤

### Step 1: 询问用户角色和目标

向用户展示选项：

```
你的角色是？
1. 业务人员 — 想用低代码搭建业务功能（不写代码）
2. 前端开发者 — 想理解前端架构并做二次开发
3. 后端开发者 — 想理解后端架构并扩展模块
4. 架构师 — 想全面理解系统设计
5. 运维人员 — 想部署和维护系统

你的目标是？
A. 快速上手（1-2 天能跑起来）
B. 深入理解（1 周掌握核心原理）
C. 二次开发（能扩展新功能）
D. 部署上线（生产环境运维）
```

### Step 2: 根据组合推荐学习路径

#### 业务人员 + 快速上手

```
## 学习路径：业务人员快速上手（1-2 天）

### Day 1: 低代码核心
1. 读 [操作手册使用指引](docs/架构迭代/6、培训与操作手册/5、JNPF-v5.2操作手册使用指引.md)（15 分钟）
2. 读 [客户演示手册](docs/v52-demo-manual.md) 第一章（30 分钟）
3. 跟着演示手册实操：搭建"客户管理"功能（1 小时）

### Day 2: 进阶
4. 读 [手册一：主WEB低代码](docs/架构迭代/6、培训与操作手册/2、手册一-主WEB低代码代码生成操作手册.md) 第三-六章
5. 实操：搭建"工单管理"或"BOM 管理"
```

#### 后端开发者 + 二次开发

```
## 学习路径：后端开发者二次开发（1 周）

### Day 1-2: 架构理解
1. 读 [CLAUDE.md](CLAUDE.md) — 项目宪法、架构红线、构建命令
2. 读 [03-业务模块深度剖析](docs/architecture/v52/03-application-modules-deep-dive.md)
3. 读 [开发规范](docs/development/guide.md)

### Day 3-4: 核心机制
4. 读 [10-工作流引擎深度剖析](docs/architecture/v52/10-workflow-engine-deep-dive.md)
5. 读 [.claude/rules/jnpf-expert-traps.md](.claude/rules/jnpf-expert-traps.md) — 避坑指南

### Day 5: 实战
6. 跟着 [手册一](docs/架构迭代/6、培训与操作手册/2、手册一-主WEB低代码代码生成操作手册.md) 生成一个功能
7. 手写一个 Service 扩展功能
8. 运行 pre-commit 检查验证
```

#### 架构师 + 深入理解

```
## 学习路径：架构师全面理解（1-2 周）

### Week 1: 架构文档
1. 读 [CLAUDE.md](CLAUDE.md)
2. 依次读 docs/architecture/v52/ 下的 01-11 全部文档
3. 读 [OpenSpec 知识库](openspec/specs/) 的所有 spec

### Week 2: 扩展评估
4. 读 [物联网项目开发能力扩展评估](docs/架构迭代/2、架构迭代方案设计/3、物联网项目开发能力扩展评估.md)
5. 读 [部署与运维](docs/架构迭代/5、部署与运维/) 全部文档
6. 读 [.claude/rules/](.claude/rules/) 全部规则文件
```

#### 运维人员 + 部署上线

```
## 学习路径：运维部署（3-5 天）

### Day 1-2: 环境准备
1. 读 [阶段一-环境准备](docs/架构迭代/5、部署与运维/01-阶段一-环境准备.md)
2. 读 [阶段二-数据库初始化](docs/架构迭代/5、部署与运维/02-阶段二-数据库初始化.md)

### Day 3-4: 服务部署
3. 读 [阶段三-后端服务启动](docs/架构迭代/5、部署与运维/03-阶段三-后端服务启动.md)
4. 读 [阶段四-前端构建与Nginx部署](docs/架构迭代/5、部署与运维/04-阶段四-前端构建与Nginx部署.md)
5. 读 [阶段五-辅助服务部署](docs/架构迭代/5、部署与运维/05-阶段五-辅助服务部署.md)

### Day 5: 加固与验证
6. 读 [阶段六-生产加固](docs/架构迭代/5、部署与运维/06-阶段六-生产加固.md)
7. 读 [阶段七-端到端验证](docs/架构迭代/5、部署与运维/07-阶段七-端到端验证.md)
```
