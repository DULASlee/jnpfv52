# Session Key Points — 2026-06-23 SA Gate Fatal Fixes

## Key Technical Decisions

1. **Fail-Closed 策略绝对化** — SemanticFitnessValidator 所有异常路径（LLM失败/JSON解析失败/超时/未知异常）统一返回 `Passed=false`。企业级安全红线：宁拒不放。
2. **宽容 JSON 提取三重防护** — `ExtractJson`：去 markdown 包裹 → 提取 `{...}` → `JsonDocument.Parse` 预校验 → 尾逗号修复回退。覆盖 DeepSeek 等模型常见的 4 种非标准输出模式。
3. **Record 不可变性安全** — `PostProcess` 使用 `.ToList()` 可变拷贝 + `with` 表达式创建新实例。永远不在 record 上直接 `.Add()`。
4. **Fake + 显式接口实现替代 Moq** — Moq 在 CancellationToken 参数匹配上不稳定，改用显式接口实现 Fake 类，确定性 100%。
5. **`$$"""` (双美元) raw string 用于 JSON 模板** — `$"""` 与 LLM Prompt 中的 `{{` JSON 冲突。`$$"""` 单大括号字面量 + `{{x}}` 插值。

## Pitfalls and Avoidance Strategies

1. **Moq + CancellationToken = 不可靠** → 直接用显式接口实现 Fake，零匹配开销
2. **record 默认值与 null 检查互斥** → 反序列化后不能依赖 null 判断缺失字段，需检测空列表+零值组合
3. **集成测试不能依赖 `new` 方法隐藏** → 依赖注入控制行为，不依赖多态重写
4. **C# raw string + JSON = 语法地雷** → 用 `$$"""` 模式，JSON 大括号保持原样
