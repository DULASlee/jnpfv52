## 2. 扫描器规格（tools/JNPF.Audit.Scanner）

- 控制台，net8.0，引用 `Microsoft.CodeAnalysis.CSharp 4.8.0`
- CC 计算复制自 `CyclomaticComplexityWalker`（JNPF.Analyzers），文件头注释「同源口径」；**零改动既有项目**
- 每方法输出：File / Class / Method / CC / LOC / Params / NestingDepth / IfCount / SwitchCases / TryCatch / Returns / Calls
- 汇总输出：文件数、类数、方法数（补 Scope 实测）、A/B/C 分层计数
- 排除：`bin/obj`、`tests/`、`tools/`（沿用 BaselineGeneratorTests 口径）
- Cognitive Complexity 不支持 → `[NOT MEASURED]`，以 NestingDepth+Branches 近似
