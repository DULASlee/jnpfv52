| 步 | 动作 | 门禁 |
|----|------|------|
| S1 | **特征用例前置**：补齐全分支特征用例（含规格 §4.2 对应怪异行为用例），对当前实现跑绿并锁定为金标准 | 新增用例全绿 |

| S3 | **等价验证**：S1 特征集 + 既有测试 + 签名契约测试全绿；经编译器链路的需补跑路由快照零 diff | 逐字一致 |
| S4 | **基线销账**：从 `complexity-baseline.json` 移除该条目；清除方法上方 `// TODO: CCxx 超标…` 注释；`TECH-DEBT.md` 卡片对应行更新 | CI（`/p:CI_BUILD=true`）0 错 |
| S5 | **提交**：单提交含（拆分代码 + 用例 + 基线 + 看板），消息格式 `refactor(D1): <方法> 拆分（CC<旧>→<新>，基线销账）` | 提交通过 hooks |
