## 2. Hard Gates (constitution — non-negotiable)

[保留 v1.0 的 6 条] + 新增 5 条：

### 2.7 IRON-TABLE-01  No Change ≠ No Action

NO-CHANGE 必须产出 8 维度证据（column_naming / data_type / nullable_contract / tenant_model / audit_model / index_contract / constraint_contract / security_boundary），全部 PASS 才能下结论。

### 2.9 IRON-TABLE-03  Every Table Needs Target Contract

P0 表（identity / tenant / permission / user）必须最先审计，输出 security_boundary_audit 完整 4 维度证据。

### 2.11 IRON-TABLE-05  Performance Claim Requires Measurement

禁止"加索引 = 性能提升"逻辑推理。每张 REFACTORED 表必须产出 Before/After measurement（logical_reads / cpu_ms / duration_ms），logical_reads_reduction >= 50% 才算有效。

## 11. Schema Migration Governance（v2.0 新增）

### 11.1 三分类

| Type | 特征 | 处理 |
|------|------|------|
| A: Pure Technical | 拼写错误、命名风格统一 | 直接 sp_rename |
| B: Semantic Change | 字段语义变了 | 双写兼容 6 个月 |

### 11.2 Type C 识别

```python
if table_name.startswith(("wform_", "ext_", "lowcode_")):

        action="MANUAL_GOVERNANCE_REQUIRED"
    )
```

### 11.3 迁移模式

```yaml
type_a:
  pattern: EXEC sp_rename 'schema.table.old', 'new', 'COLUMN'
  rollback: EXEC sp_rename 'schema.table.new', 'old', 'COLUMN'
  entity_sync: REQUIRED  # [SugarColumn] 同步

type_b:
  pattern: ALTER TABLE ADD new_col + UPDATE ... SET new = old + 6 months dual-write
  rollback: DROP COLUMN new_col
  entity_sync: REQUIRED  # [Obsolete] 旧字段标记

type_c:
  pattern: MANUAL_GOVERNANCE_REQUIRED
  skill_action: SKIP

```sql
-- scripts/database-modernization/phase2-p0-security/01-add-password-fields.sql
-- 阶段 2.1：在 base_user 上新增密码相关字段（保留旧 f_password 字段，6 个月兼容期）

BEGIN TRAN;

IF NOT EXISTS (SELECT 1 FROM sys.columns WHERE object_id = OBJECT_ID('base_user') AND name = 'f_password_hash')
    ALTER TABLE base_user ADD f_password_hash nvarchar(255) NULL;

IF NOT EXISTS (SELECT 1 FROM sys.columns WHERE object_id = OBJECT_ID('base_user') AND name = 'f_password_algo')
    ALTER TABLE base_user ADD f_password_algo nvarchar(20) NULL DEFAULT 'LEGACY_MD5';

IF NOT EXISTS (SELECT 1 FROM sys.columns WHERE object_id = OBJECT_ID('base_user') AND name = 'f_password_updated_at')
    ALTER TABLE base_user ADD f_password_updated_at datetime2(7) NULL;

IF NOT EXISTS (SELECT 1 FROM sys.columns WHERE object_id = OBJECT_ID('base_user') AND name = 'f_password_version')
    ALTER TABLE base_user ADD f_password_version int NULL DEFAULT 1;

-- 数据回填：新字段用旧字段值
UPDATE base_user
SET f_password_hash = f_password,
    f_password_algo = 'LEGACY_MD5',
    f_password_updated_at = ISNULL(f_change_password_date, SYSUTCDATETIME()),
    f_password_version = 1
WHERE f_password IS NOT NULL AND f_password_hash IS NULL;

COMMIT;
GO
```

```sql
-- scripts/database-modernization/phase2-p0-security/05-classify-schema-changes.sql
-- 输出 16+ 列名漂移的 Type A/B/C 分类，作为下一阶段真迁移的依据

SELECT
    TABLE_NAME,
    COLUMN_NAME,
    CASE
        WHEN TABLE_NAME LIKE 'wform[_]%' OR TABLE_NAME LIKE 'ext[_]%' OR TABLE_NAME LIKE 'lowcode[_]%'
        THEN 'C: Low-Code Dynamic (MANUAL_GOVERNANCE_REQUIRED)'
        WHEN TABLE_NAME IN ('BASE_AI_EVAL_CASE', 'BASE_AI_PIPELINE_STAGE_CONFIG', 'BASE_AI_UI_TEMPLATE')
            AND COLUMN_NAME IN ('F_Name', 'F_Stage', 'F_Rating', 'F_Category')
        THEN 'B: Semantic Change (DUAL_WRITE_6_MONTHS) [v1 violation: F_Name substituted F_CaseCode]'
        WHEN TABLE_NAME = 'base_user' AND COLUMN_NAME = 'fOpenId'
        THEN 'A: Pure Technical (DIRECT_RENAME)'
        ELSE 'B: Semantic Change (DUAL_WRITE_6_MONTHS)'
    END AS Migration_Type,
    'Pending Phase 3 Real Migration' AS Status
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = 'dbo'
  AND (
    (TABLE_NAME = 'wform_contractapproval' AND COLUMN_NAME IN ('F_ApplyUser', 'F_ApplyDate'))
    OR (TABLE_NAME = 'wform_salesorder' AND COLUMN_NAME IN ('F_ApplyUser', 'F_ApplyDate'))
    OR (TABLE_NAME = 'wform_purchaselist' AND COLUMN_NAME IN ('F_ApplyDate'))
    OR (TABLE_NAME = 'wform_travelapply' AND COLUMN_NAME IN ('F_ApplyUser'))
    OR (TABLE_NAME = 'ext_project_gantt' AND COLUMN_NAME IN ('f_task_name'))
    OR (TABLE_NAME = 'kg_pattern_usage' AND COLUMN_NAME IN ('target_type'))
    OR (TABLE_NAME = 'base_user' AND COLUMN_NAME = 'fOpenId')
    OR (TABLE_NAME = 'BASE_AI_EVAL_CASE' AND COLUMN_NAME IN ('F_Name', 'F_Stage'))
    OR (TABLE_NAME = 'BASE_AI_GENERATED_PROJECT' AND COLUMN_NAME IN ('F_ProjectName', 'F_PipelineStatus'))
    OR (TABLE_NAME = 'BASE_AI_PIPELINE_STAGE_CONFIG' AND COLUMN_NAME = 'F_Stage')
    OR (TABLE_NAME = 'BASE_AI_UI_TEMPLATE' AND COLUMN_NAME IN ('F_Category', 'F_Rating'))
  )
ORDER BY Migration_Type, TABLE_NAME, COLUMN_NAME;
