# JNPF 后端类级代码审计扫描与填写模板 v1.1（JNPF 适配修订版）

> **版本**：v1.1（基于 v1.0 修订，针对 JNPF 项目架构适配）  
> **修订日期**：2026-08-27  
> **上位**：《类级螺旋（L2）专家级重构方案 v2.0》《MASTER 总体实施计划》  
> **使用方式**：将本文档提供给 AI 大模型。AI 逐维度扫描代码后，在下方表格中填入发现的问题。每张表可单独提交，最后汇总。  
> **严重级别**：🔴 致命（崩溃/泄漏/数据错乱/安全漏洞）｜🟠 严重（性能/死锁/资源泄漏）｜🟡 警告（坏味道/可维护性）｜🔵 建议（最佳实践偏离）  
> **填写规则**：每行一个问题；文件路径必须精确到行号；代码片段截取关键行（不超过 3 行）；修复建议必须可执行。
