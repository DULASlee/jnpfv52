> 三个月后复盘调整。
> 生效日期：2026-05-31

---

## 一、五条底线（可背诵版）

① **没有代码 = 没有修复。** 禁止"已确认""无需修复"无代码断言。必须贴 before/after 完整方法体。

② **没有运行 = 没有验证。** 数据流/中间件/配置变更必须冒烟测试，贴实际输出。编译≠正确。

③ **没有 grep = 没有清除。** 声称"无残留"必须在**项目根目录**执行 grep，附终端输出。

④ **没有查定义 = 没有核实。** 引用常量/枚举/配置键必须先 grep 定义处，贴源码行+实际值。

⑤ **没有注册 = 没有新增。** 新增中间件/服务/Enricher/Filter 必须同时贴：新增代码 + 注册代码 + 运行时执行证据。

---

## 二、交付格式（按影响等级分级）

| 等级 | 触发条件 | 交付要求 |
|---|---|---|
| **S 微小** | 文案/注释，不涉及逻辑 | before/after 代码 + 编译输出 |
| **A 普通** | 单文件逻辑修改 | 完整交付（代码对照 + 依赖核实 + grep + 编译 + 运行时） |
| **B 重大** | 跨模块/中间件/数据流 | A 全部 + 架构师审查 |
| **C 核心** | 核心链路/多租户/安全 | B 全部 + L4 回归验证 |

等级由修改内容决定，不由修改人决定。不确定时按更高级别。

---

## 三、验证级别

| 级别 | 触发条件 | 排除条件 |
|---|---|---|
| L0 编译 | 所有修改 | 无 |
| L1 单元 | 新增方法/工具类 | 纯文案 |
| L2 集成 | 跨模块/DI 变更 | 纯单方法内部 |
| L3 冒烟 | 数据流/中间件/配置 | 无（凡触发必执行） |
| L4 回归 | 核心链路修改 | 非核心（架构师判定） |

**可自行升级，不可自行降级。有疑问按高级别。**

## 五、六类变更强制检查项

> 详细检查清单见 `docs/铁律/checklists.md`，以下为摘要索引。

**A 日志字段：** 字段名↔DB列名↔LogContext key 三方一致？运行时 JSON 确认有值？

**B async void：** 改签名→接口+实现+调用方全部同步？`grep -rn "方法名"` 贴输出。

**C 配置变更：** 数值手算一遍。bool 方向确认。多环境同步。启动验证。

**D 接口签名：** `grep -rn "IInterfaceName"` 找全实现和调用方，逐个更新。

**E 中间件/Filter：** 注册位置和顺序正确？所有分支都有 await？LogContext using 覆盖 _next？

**F 多租户：** ChangTenant 并发安全？CopyNew 隔离？日志写入不串租户？

**G 数据库：** 实体类改了→迁移脚本生成并执行？新字段默认值？

**H 移除/替换：** 移除后 grep 残留为零，贴输出。

## 六、编译铁律

**编译前先杀进程：** `tasklist | findstr "JNPF.API.Entry"` → 有则 `taskkill /F /IM` → 等 2 秒 → 再编译。禁止在 API 运行时编译后拿文件锁定当借口。

**编译输出要求：** 贴 `dotnet build` 输出 + `grep -c "error CS"` = 0。

---

## 七、禁止用语

| 禁止 | 替代 |
|---|---|
| 已确认没问题 | 贴代码/日志 |
| 代码已正确 | 贴代码原文 |
| 无需修复 | 贴代码+解释 |
| 编译通过 | 贴编译输出 |
| 已冒烟测试 | 贴步骤+输出 |
| 后续考虑 | 现在做，或标记"未完成" |
| 应该/理论上/正常情况下 | = 没测试过 |
| 参考XXX实现 | 贴原文+行号 |
| 沿用原有逻辑/和之前一样 | 贴前后代码对比 |

---

## 八、打回与信用

**直接打回：** 缺代码对照 / 用禁止用语 / 声称无需修复不贴代码 / 声称已测试不贴输出。

**三次打回 → 质量事件**：当面演示修复全过程，记入项目质量档案。

**质量信用：**

| 连续通过 | 权益 |
|---|---|
| 5 次 | L2 及以下可自行裁定等级 |
| 10 次 | 非核心模块可省略部分交付模板 |
| 20 次 | 免审通道，架构师抽样审查 |

一次打回信用归零。质量事件信用归零 + 30 天禁用免审。
