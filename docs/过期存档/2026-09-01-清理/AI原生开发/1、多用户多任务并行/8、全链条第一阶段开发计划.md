阶段一要回答的核心问题：**后续 10 个 Skill 共享的 IR 运行时数据通道是否就绪，且能否在「提交需求」页逐步验收每一步实现？**

### 0.2 核心策略（与总体计划的关键差异）

总体计划原描述偏「后台基础设施先行」。经审核后，阶段一调整为：

> **不做「后台先建完再对接前端」。**  
> 每完成一个后端组件，**当天**就在「提交需求」页（`/studio/ai/submit-requirement`）可观测、可点击、可验收。

因此阶段一必须**同时**交付：

1. **IR 运行时基础设施**（数据表 + C# 服务）
2. **Pipeline Observatory（IR 观测台）**— 嵌入提交需求页的 E2E 验证壳

后者是阶段一的**第一优先级**，不是锦上添花。

### 4.4 投影引擎（核心逻辑）

```csharp
public async Task<IRSnapshot> RebuildAsync(string tenantId, string projectId)
{
    var events = await _db.Queryable<AiIrEventEntity>()
        .Where(e => e.TenantId == tenantId && e.ProjectId == projectId)
        .OrderBy(e => e.Sequence).ToListAsync();

    var fragments = new Dictionary<string, FragmentState>();
    foreach (var evt in events)
    {
        if (string.IsNullOrEmpty(evt.FragmentId)) continue;
        if (!fragments.TryGetValue(evt.FragmentId, out var frag))
            frag = new FragmentState { FragmentId = evt.FragmentId, Type = evt.FragmentType };
        ApplyEvent(frag, evt);
        fragments[evt.FragmentId] = frag;
    }
    await UpsertSnapshotsAsync(tenantId, projectId, fragments);
    return new IRSnapshot { ProjectId = projectId, Fragments = fragments.Values.ToList() };
}
```

### 4.5 稳定性门控（TDR-002）

const int RequiredSaSteps = 9;

    .Where(e => e.EventType == "SA_Step_Completed" && e.FragmentId == fragmentId)

if (completed >= RequiredSaSteps && currentState != "stable")
{
    await AppendEvent(new { EventType = "FragmentStabilized", ... });

}
