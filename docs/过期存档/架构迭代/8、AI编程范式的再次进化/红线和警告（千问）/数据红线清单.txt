---------------------------------------------------------------------------
Trap 2 — Mapster Adapt() 审计字段覆盖
---------------------------------------------------------------------------
严重程度: 数据完整性破坏

症状: input.Adapt<Entity>() 全量映射 → CreateTime/CreateUserId/TenantId 被覆盖
根因: Adapt() 拷贝所有同名字段（含审计字段），更新操作静默丢失原始审计数据
修复:
  1. 先查原始实体: var entity = await db.Queryable<T>().InSingleAsync(id)
  2. 再映射: input.Adapt(entity)（保留已有审计字段）
  3. 或显式排除: .Ignore(dest => dest.CreateTime)
禁止: db.Updateable(input.Adapt<T>()) 盲全量覆盖

---------------------------------------------------------------------------
Trap 3 — SqlSugar导航属性序列化 N+1
---------------------------------------------------------------------------
严重程度: 性能杀手

症状: 返回实体列表 → JSON序列化触发导航属性懒加载 → 100条×3属性=300次查询
根因: SqlSugar导航属性默认懒加载，JSON序列化器访问时触发DB查询
修复:
  1. 急切加载: .Includes(o => o.User, o => o.Department)
  2. DTO投影: .Select(x => new ListOutput {...})（DTO无导航属性）
禁止: 直接返回含导航属性的实体列表

---------------------------------------------------------------------------
Trap 11 — Mapster 循环引用栈溢出
---------------------------------------------------------------------------
严重程度: 运行时崩溃

症状: entity.Adapt<Dto>() 含循环引用 → Mapster无限递归 → StackOverflow
根因: JNPF实体常见循环引用（User→Department→Users→Department...）
修复:
  1. 用.Select()投影到DTO
  2. 配置Mapster MaxDepth限制递归深度
禁止: 直接Adapt含循环引用的实体图

---------------------------------------------------------------------------
Trap 14 — 无分页查询 → OOM
---------------------------------------------------------------------------
严重程度: 生产事故（大数据量时）

症状: .ToListAsync() 在10条数据开发环境正常，10万条生产环境OOM/超时
根因: SqlSugar和Dapper无默认分页
修复: 列表端点 ALWAYS 使用 .ToPageListAsync(currentPage, pageSize)，默认pageSize=20
禁止: .ToListAsync() 用于可能超过100条的查询
例外: 导出场景 → 流式查询或批量读取

---------------------------------------------------------------------------
Trap 10 — EventBus 至少一次送达
---------------------------------------------------------------------------
严重程度: 业务重复执行

症状: 发布一次事件 → RabbitMQ可能重复投递 → 同一订单触发两个工作流
修复: 事件处理器 MUST 幂等：查询目标状态或检查已处理的EventId
禁止: 假设事件只触发一次

---------------------------------------------------------------------------
Native SQL 安全规范
---------------------------------------------------------------------------
来源: sql-safety.md

禁止:
  - $"SELECT * FROM Users WHERE Name = '{userInput}'"
  - "SELECT * FROM Users WHERE Name = '" + userInput + "'"
  - $"DROP TABLE {tableName}"
  - $"DELETE FROM Log WHERE Date < '{date}'"

必须:
  - db.Queryable<User>().Where(u => u.Name == userInput).ToList()
  - Ado.SqlQuery("SELECT * FROM Users WHERE Name = @name", new SqlSugarParameter("@name", userInput))
  - 动态表名/列名 → 白名单验证后方可拼接

白名单示例:
  private static readonly HashSet<string> AllowedTables = new() { "BASE_USER", "FLOW_TASK" };
  if (!AllowedTables.Contains(tableName)) throw Oops.Bah("Invalid table name");
