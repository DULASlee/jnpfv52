### 模块1：核心架构的核心技术

**你需要搞清楚的10个关键问题：**

```
1. 项目是单体还是微服务？服务间如何通信？(HTTP/gRPC/消息队列)

7. 配置管理？(appsettings.json结构、环境变量、动态配置)
```

**前端6大核心机制深度分析：**

**① 动态路由机制**
```javascript
// permission.js 中的核心流程
router.beforeEach(async (to, from, next) => {
  if (hasToken) {
    if (to.path === '/login') {
      next({ path: '/' })
    } else {
      if (hasRoles) {
        next()
      } else {
        // ★ 关键：从后端获取菜单 → 转为路由 → 动态添加
        const { menus } = await store.dispatch('user/getInfo')
        const routes = await store.dispatch('permission/generateRoutes', menus)
        routes.forEach(route => router.addRoute(route))
        next({ ...to, replace: true })
      }
    }
  } else {
    // 白名单页面直接放行
    if (whiteList.includes(to.path)) next()
    else next(`/login?redirect=${to.path}`)
  }
})
```

```javascript
// 响应拦截器
service.interceptors.response.use(response => {
  const res = response.data
  if (res.code !== 200) {
    // Token过期处理

    }
    return Promise.reject(res)
  }
  return res
})
```

**最后一句话：** 读源码最忌讳的是"从第一行读到最后一行"。正确的方法是 **带着问题追链路** —— 先在界面上点一下某个按钮，然后从前端事件追到API调用，再追到后端处理，最后追到数据库操作。这样一条链路走通，比泛读十个文件有效得多。
