# ADR-006: CopyNew 行为 — 保留查询过滤器

**状态:** Final
**日期:** 2026-05
**阶段:** Stage 0

## 决策内容

`ISqlSugarClient.CopyNew()` 创建的新实例完整保留原实例上的所有查询过滤器（租户过滤器、软删除过滤器等），不因拷贝而丢失。

## 理由

查询过滤器是多租户数据隔离和软删除的核心防线。如果 `CopyNew()` 不继承过滤器，每次拷贝后需手动重新注册，极易遗漏导致数据泄露。保留过滤器保证拷贝实例与原型的隔离策略一致。

## 备选方案

| 方案 | 优点 | 缺点 | 为何不选 |
|---|---|---|---|
| CopyNew 不继承过滤器 | 拷贝更"干净"，调用方可按需重新配置 | 必须手动重加过滤器，遗漏 = 数据泄露 | 安全风险不可接受 |
| 不使用 CopyNew，直接复用实例 | 零拷贝开销 | 并发下租户状态互相覆盖 | 违反多租户隔离 |

## 后果

**正面:** 拷贝实例自动继承所有安全策略，零配置防泄露。
**负面:** 如果某个拷贝场景不希望某些过滤器，需显式移除（极少场景）。

## 验证结果

CopyNew 后查询 SQL 包含 TenantId 和 IsDeleted 条件，过滤器继承正常。
