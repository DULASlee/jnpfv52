# ADR-004: 匿名端点降级 — 4 级回退机制

**状态:** Final
**日期:** 2026-05
**阶段:** Stage 2

## 决策内容

未登录请求的租户识别采用 4 级回退：JWT Token 解析 → HTTP Header `X-TenantId` → QueryString `tenantId` → 默认租户。

## 理由

匿名端点（如登录页面、公开 API）需要在用户未认证时确定目标租户。4 级回退优先使用可靠来源（JWT），逐级降级到显式参数和默认值，保证登录前的租户选择可用性，同时不削弱多租户隔离。

## 备选方案

| 方案 | 优点 | 缺点 | 为何不选 |
|---|---|---|---|
| 仅 JWT 解析 | 最安全 | 未登录时无 JWT，匿名端点不可用 | 无法满足登录前租户选择需求 |
| 仅 QueryString | 实现简单 | 所有公开 URL 需强制带参，易遗漏且不雅观 | 用户体验差，安全性弱 |

## 后果

**正面:** 灵活支持登录前租户选择，向后兼容各种客户端接入方式。
**负面:** 4 级链增加解析复杂度和调试难度；QueryString 传租户 ID 有信息泄露风险（仅限非敏感场景）。

## 验证结果

编译通过；JWT/Header/QueryString/Default 四种场景测试通过。
