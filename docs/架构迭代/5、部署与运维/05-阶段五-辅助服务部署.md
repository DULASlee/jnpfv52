## 5.2 部署 Univer 报表（新） [可选]

> `[可选]` **跳过后会怎样：** 「Univer 报表设计器」不可用；低代码 CRUD、PrintDev 打印模板仍可用。

### 5.2.1 你要准备什么

- JNPF 提供的 **报表 API 服务**（监听 **32000**）  
- **报表前端静态包**（监听 **8200** 或由 Nginx 托管 `/Report`）

### 5.2.2 PC 前端对接（已内置）

开发环境 `jnpf-web-vue3/.env.development` 示例：

```bash
VITE_PROXY = [["/dev","http://localhost:30000"], ["/reportDev","http://localhost:32000"]]
VITE_GLOB_REPORT_API_URL=/reportDev
```

生产 Nginx 增加：

```nginx
location /reportDev/ {
    proxy_pass http://127.0.0.1:32000/;
}

location /Report/ {
    proxy_pass http://127.0.0.1:8200/;
}
```

### 验证

| # | 验证什么 | 怎么验证 | 通过长什么样 | 失败长什么样 |
|---|----------|----------|-------------|-------------|
| 1 | 报表 API | `curl http://localhost:32000/` 或交付包健康检查 URL | HTTP 200 / 文档页 | Connection refused → 服务未起 |
| 2 | 报表静态 | 浏览器 `http://localhost:8200` | 静态资源页 | 404 → 静态未部署 |

## 5.4 部署文件预览 FileServer [可选]

> **kkFileView** 类服务：把 Office/PDF 转成 HTML 预览。后端 `App.json` 中 `PreviewType: "kkfile"`。

### 5.4.1 启动预览服务

按交付包说明启动（典型 **30090** 端口），确保可访问：

```
http://127.0.0.1:30090/FileServer
```

### 5.4.2 后端配置

确认 `application/JNPF.API.Entry/Configurations/App.json`：

```json
"PreviewType": "kkfile",
"KKFileDomain": "http://127.0.0.1:30090/FileServer"
```

生产同域部署时改为：

```json
"KKFileDomain": "http://你的域名/FileServer"
```

并确保阶段四 Nginx 已配置 `location /FileServer`。

### 验证

| # | 验证什么 | 怎么验证 | 通过长什么样 | 失败长什么样 |
|---|----------|----------|-------------|-------------|
| 1 | 预览服务 | 浏览器打开 `http://localhost:30090/FileServer` | kkFileView 欢迎页或静态资源 | 连接拒绝 → 5.4.1 |
| 2 | 联调 | PC 前端上传附件后点「预览」 | 新窗口打开预览页 | 空白 → 检查 KKFileDomain 与 Nginx |

## 5.5 更新 Nginx 与 App.json [可选]

若 5.2–5.4 任一项启用，合并 Nginx 片段后：

```powershell

```
