## 6.1 更换 JWT 与默认密码 [必选]

**当前值在** `Configurations/JWT.json` → `IssuerSigningKey`（本仓库以 `RkayGi4ltkMWrSQK...` 开头，打开文件查看全文）。

## 6.2 启用 Redis 缓存 [推荐·生产]

> **先读 `Cache.json`。** 仅当 `CacheType` 从 `MemoryCache` 改为 **`RedisCache`** 时执行。

1. 修改 `Configurations/Cache.json` → `"CacheType": "RedisCache"`，并在 `RedisConnectionString` 中加上 `password=你的密码`  
2. 安装 Redis，**密码与 JSON 中 `password=` 完全一致**（见阶段一 1.4）  
3. 重启 API

### 验证

```bash
# password 替换为 Cache.json 中与 Redis 一致的值
docker exec jnpf-redis redis-cli -a "Cache.json中的password值" keys "*"
```

登录后再查，应出现缓存 key（前缀与租户域相关）。

## 6.3 敏感配置外置 [推荐·生产]

> **不要** 把生产密码提交 Git。推荐用环境变量覆盖：

| 配置项 | 环境变量示例 |
|--------|-------------|
| 主库密码 | `ConnectionStrings__ConnectionConfigs__0__Password` |
| Job 库密码 | `ConnectionStrings__ConnectionConfigs__1__Password` |
| JWT 密钥 | `JWTSettings__IssuerSigningKey` |
| Redis | `Cache__RedisConnectionString` |

🪟 **Windows 服务 / IIS**：在系统环境变量或 IIS 配置中设置。  
🐧 **systemd**：`Environment=` 行（见阶段三 3.5）。

`ConnectionStrings.json` 中 Password 可留空占位，由环境变量注入。

## 6.4 日志与磁盘 [推荐·生产]

日志配置：`Configurations/Logging.json`

```
logs/{yyyyMMdd}/{yyyyMMdd}_{Level}.log
```

🪟 **Windows 11**：

```powershell
# API 工作目录下
Get-ChildItem -Path "$JNPF_ROOT\application\JNPF.API.Entry\logs" -Recurse -ErrorAction SilentlyContinue | Select-Object -First 5
```

> **期望：** 有按日期分目录的 `.log` 文件。

建议：

- 磁盘监控：日志目录 ≥ 10GB 可用  
- `MaxRollingFiles: 30` 可按合规要求调整  
- 生产 LogLevel 默认 `Information`，故障排查时临时改 `Debug`

## 6.5 数据库备份计划 [推荐·生产]

### 6.5.1 手动备份（验证用）

🪟 **Windows 11**（[数据库管理员]）：

```powershell
$BackupDir = "C:\JNPF\Backup"
New-Item -ItemType Directory -Force -Path $BackupDir
sqlcmd -S $DB_HOST -U $DB_USER -P "$DB_PASS" -Q "BACKUP DATABASE [$MAIN_DB] TO DISK=N'$BackupDir\${MAIN_DB}_$(Get-Date -Format yyyyMMdd).bak' WITH INIT"
sqlcmd -S $DB_HOST -U $DB_USER -P "$DB_PASS" -Q "BACKUP DATABASE [$JOB_DB] TO DISK=N'$BackupDir\${JOB_DB}_$(Get-Date -Format yyyyMMdd).bak' WITH INIT"
```

### 6.5.2 自动备份

- Windows：任务计划程序，每日执行上述脚本  
- Linux：`cron` + `sqlcmd` 或 SQL Server Linux 备份工具

### 验证

```powershell
Get-ChildItem C:\JNPF\Backup\*.bak | Select-Object Name, Length, LastWriteTime
```

> **期望：** 两个 `.bak` 文件，大小 > 0。

## 6.6 配置 HTTPS [可选]

> `[可选]` 内网 PoC 可用 HTTP；公网 **必须** HTTPS。

### Nginx 示例（Let's Encrypt 或企业证书）

```nginx
server {
    listen 443 ssl;
    server_name your.domain.com;
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;
    # ... 其余 location 同阶段四 4.5.2 ...
}

server {
    listen 80;
    server_name your.domain.com;
    return 301 https://$host$request_uri;
}
```

同步修改：

- `App.json` → `Message.ApiDoMain`、`Domain`  
- 前端 `dist/_app.config.js` 中 API/WS 为 `https://` / `wss://`
