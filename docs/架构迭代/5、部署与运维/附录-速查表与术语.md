## 附录 D — 常见报错速查（按阶段）

| 阶段 | 报错/现象 | 原因 | 解决 |
|------|-----------|------|------|
| 一 | `dotnet: command not found` | .NET 未装 | 安装 .NET 6 SDK |
| 一 | `Login failed for user 'sa'` | 密码与 ConnectionStrings.json 不一致 | 核对 `$DB_PASS` 与 JSON 中 `Password` |
| 二 | `Directory lookup for file ... failed` | CREATE DATABASE 路径不对 | 改脚本路径或先建空库 |
| 二 | 登录无 admin | DDL 无 seed | 阶段二 2.5 |
| 三 | SQL connection error | ConnectionStrings 错 | 3.3.1 + sqlcmd 验证 |
| 三 | `NU1101` NuGet | 网络 | 国内 NuGet 源 + restore |
| 三 | 端口被占用 | 旧 dotnet | 3.1 清理 |
| 四 | 前端仍请求 :5000 | `.env.production` 未改 | 4.1.1 重建 dist |
| 四 | 502 Bad Gateway | API 未起 | 阶段三 |
| 四 | 刷新 404 | SPA 未配置 try_files | 4.5.2 |
| 五 | 预览空白 | FileServer 未起 | 5.4 |
| 五 | 报表打不开 | :32000/:8200 未部署 | 5.2 |
| 六 | 多实例登录互踢 | 未用 Redis | 6.2 |
| 七 | 401 频繁 | Token/Redis | 6.2、Cors.json |
| 七 | 大屏 API 404 | 未引用 VisualData | 3.2 |

## 附录 E — SQL 脚本说明（实测 2026-05-26）

| 文件 | 大小 | 内容 | SQL Server 部署 |
|------|------|------|----------------|
| `web/主库脚本.sql` | ≈2.1 MB | **主库** `ZXAF_V1_DevTest1` + 全部业务表（**18× flow_***、**8× blade_visual_***） | ✅ 必须执行 |
| `web/jnpf_sundial_init_sqlserver.sql` | ≈2.8 KB | **调度库** `jnpf_sundial` + Job 表 | ✅ 必须执行 |
| `web/jnpf_sundial_init.sql` | ≈10 KB | 调度库 Oracle 语法 | ❌ 勿在 SQL Server 执行 |
| `web/jnpf事件库脚本.sql` | ≈12 KB | 事件库扩展 | 按需 |

**与架构文档 05/10 的关系：** 05/10 检索的是 `jnpf_sundial_init.sql`（调度库 Oracle 脚本），故「不含 BLADE/FLOW」结论正确；业务 DDL 在 **`主库脚本.sql`**。05/10 的 `【待 DDL 验证】` 应理解为针对 init 脚本；主库脚本已含完整表结构。

**seed 数据：** 上述 SQL **均无 INSERT**；登录需 `.bak` 或 JNPF seed 包（见阶段二 2.5）。
