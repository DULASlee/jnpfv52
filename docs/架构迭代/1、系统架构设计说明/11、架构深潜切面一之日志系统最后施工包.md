### 任务1A：TraceIdMiddleware

**目标**：每个HTTP请求生成唯一TraceId，注入响应头和请求上下文。

**新增文件**：`Middleware/TraceIdMiddleware.cs`

```csharp
using System.Diagnostics;

namespace YourProject.Middleware;

public class TraceIdMiddleware
{
    private const string TraceIdHeader = "X-Trace-Id";
    private readonly RequestDelegate _next;

    public TraceIdMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        // 优先从请求头取（分布式调用场景），否则生成新的
        var traceId = context.Request.Headers[TraceIdHeader].FirstOrDefault()
                      ?? Activity.Current?.Id
                      ?? Guid.NewGuid().ToString("N");

        // 存入HttpContext.Items（传统访问方式）
        context.Items["TraceId"] = traceId;

        // 存入AsyncLocal（异步上下文传播，覆盖Task.Run等场景）
        TraceContext.TraceId = traceId;

        // 写入响应头
        context.Response.OnStarting(() =>
        {
            context.Response.Headers[TraceIdHeader] = traceId;
            return Task.CompletedTask;
        });

        await _next(context);
    }
}

/// <summary>
/// 异步上下文中的TraceId传播
/// 解决HttpContext.Items在Task.Run/ThreadPool中不可访问的问题
/// </summary>
public static class TraceContext
{
    private static readonly AsyncLocal<string> _traceId = new();

    public static string TraceId
    {
        get => _traceId.Value ?? "unknown";
        set => _traceId.Value = value;
    }
}
```

**注册**（在 `Startup.cs` 或 `Program.cs` 的管道配置中）：

```csharp
// 放在所有中间件的最前面
app.UseMiddleware<TraceIdMiddleware>();
```

**验证**：启动项目，任意请求响应头中应包含 `X-Trace-Id`。

```csharp
using Serilog;
using Serilog.Events;
using Serilog.Formatting.Json;

namespace YourProject.Infrastructure;

public static class SerilogBootstrap
{
    public static void Configure(IConfiguration cfg)
    {
        var logDir = cfg["Logging:File:LogDir"] ?? "logs";

        // 根据配置选择格式（详见第八节格式决策）
        var fileFormatter = cfg["Logging:Seq:Enabled"] == "true"
            ? new Serilog.Formatting.Compact.CompactJsonFormatter() as ITextFormatter
            : new JsonFormatter(renderMessage: true);

        Log.Logger = new LoggerConfiguration()
            .MinimumLevel.Information()
            .MinimumLevel.Override("Microsoft", LogEventLevel.Warning)
            .MinimumLevel.Override("System", LogEventLevel.Warning)
            .MinimumLevel.Override("SqlSugar", LogEventLevel.Warning)
            .Enrich.WithEnvironmentName()
            .Enrich.WithProcessId()
            .Enrich.WithThreadId()
            .Enrich.FromLogContext()

            // 错误日志
            .WriteTo.File(
                formatter: fileFormatter,
                path: Path.Combine(logDir, "error-.json"),
                rollingInterval: RollingInterval.Day,
                restrictedToMinimumLevel: LogEventLevel.Error,
                retainedFileCountLimit: 30,         // 保留30天
                fileSizeLimitBytes: 50 * 1024 * 1024)  // 单文件50MB上限

            // 警告日志（含慢SQL等）
            .WriteTo.File(
                formatter: fileFormatter,
                path: Path.Combine(logDir, "warning-.json"),
                rollingInterval: RollingInterval.Day,
                restrictedToMinimumLevel: LogEventLevel.Warning,
                retainedFileCountLimit: 14,         // 保留14天
                fileSizeLimitBytes: 50 * 1024 * 1024)

            // 全量日志（仅在Debug模式下启用）
            .WriteTo.File(
                formatter: fileFormatter,
                path: Path.Combine(logDir, "all-.json"),
                rollingInterval: RollingInterval.Day,
                restrictedToMinimumLevel: LogEventLevel.Information,
                retainedFileCountLimit: 7,
                fileSizeLimitBytes: 100 * 1024 * 1024)

            // Seq可选接入
            .WriteTo.Conditional(
                _ => cfg["Logging:Seq:Enabled"] == "true",
                sink => sink.Seq(
                    cfg["Logging:Seq:ServerUrl"] ?? "http://localhost:5341"))

            .CreateLogger();
    }
}
```

### 任务1D：LogPolicy属性定义

**目标**：定义 `[LogPolicy]` Attribute和枚举，纯定义，不改调用方。

**新增文件**：`Attributes/LogPolicyAttribute.cs`

```csharp
namespace YourProject.Attributes;

/// <summary>
/// 日志记录策略，替代原有的[IgnoreLog]和默认行为
/// </summary>
[Flags]
public enum LogPolicy
{
    /// <summary>记录请求参数、响应结果、操作人、耗时（默认行为）</summary>
    Full = 0,

    /// <summary>不记录请求参数（含密码、Token等敏感信息的接口）</summary>
    IgnoreRequest = 1,

    /// <summary>不记录响应结果（返回大数据量的接口）</summary>
    IgnoreResponse = 2,

    /// <summary>请求参数+响应结果都不记录（仅记录操作人、时间、URL、结果码）</summary>
    Minimal = IgnoreRequest | IgnoreResponse,

    /// <summary>完全不记录操作日志（健康检查、心跳等无需审计的接口）</summary>
    IgnoreAll = 4,

    /// <summary>强制记录，即使系统负载高也不丢弃（资金操作、权限变更等）</summary>
    Force = 8
}

/// <summary>
/// 标记在Service方法上，控制操作日志的记录策略
/// 用法：
///   [LogPolicy(LogPolicy.Minimal)]
///   public async Task ChangePassword(string oldPwd, string newPwd) { ... }
///
///   [LogPolicy(LogPolicy.IgnoreAll)]
///   public async Task HealthCheck() { ... }
/// </summary>
[AttributeUsage(AttributeTargets.Method, AllowMultiple = false)]
public class LogPolicyAttribute : Attribute
{
    public LogPolicy Policy { get; }

    public LogPolicyAttribute(LogPolicy policy = LogPolicy.Full)
    {
        Policy = policy;
    }
}
```

```csharp
using SqlSugar;
using Microsoft.Extensions.Caching.Memory;

namespace YourProject.EventBus.Subscriber;

public class LogEventSubscriber : IEventSubscriber
{
    private readonly IMemoryCache _cache;
    private readonly ILogger<LogEventSubscriber> _logger;

    public LogEventSubscriber(
        IMemoryCache cache,
        ILogger<LogEventSubscriber> logger)
    {
        _cache = cache;
        _logger = logger;
    }

    public async Task ExecuteAsync(OperateLogEvent eventData)
    {
        // 每次调用独立创建SqlSugarClient，从缓存中获取正确的租户连接
        var (connectionConfig, dbType) = ResolveConnectionConfig(eventData.TenantId);

        // ⚠️ 工程师必须验证：这里的ConnectionConfig构造是否与缓存结构匹配
        // 打断点检查tenantCache.connectionConfig的实际结构，对照下方代码
        using var db = new SqlSugarClient(new ConnectionConfig
        {
            DbType = dbType,
            ConnectionString = connectionConfig,
            IsAutoCloseConnection = true,
            InitKeyType = InitKeyType.Attribute
        });

        try
        {
            var entity = new SysLog
            {
                F_Id = Guid.NewGuid().ToString(),
                F_TraceId = eventData.TraceId,
                F_TenantId = eventData.TenantId,
                F_RequestUrl = eventData.RequestUrl,
                F_RequestParam = eventData.RequestParam,
                F_ActionResult = eventData.ActionResult,
                F_RequestTime = eventData.RequestTime,
                F_ElapsedTime = eventData.ElapsedTime,
                F_OperateUserId = eventData.UserId,
                F_OperateAccount = eventData.UserName,
                F_Json = eventData.JsonResult
            };

            await db.Insertable(entity).ExecuteCommandAsync();
        }
        catch (Exception ex)
        {
            // 日志写入失败不能影响业务，但必须记录
            _logger.LogError(ex,
                "操作日志写入失败, TraceId={TraceId}, TenantId={TenantId}",
                eventData.TraceId, eventData.TenantId);
        }
    }

    private (string connectionString, DbType dbType) ResolveConnectionConfig(string tenantId)
    {
        // 从缓存获取租户连接配置
        // ⚠️ 关键：工程师必须验证缓存结构的实际类型
        // 步骤：
        //   1. 找到 GlobalTenantCacheModel 类定义
        //   2. 检查是否有 connectionConfig 属性？类型是什么？
        //   3. 检查 ConfigList 的元素类型？dbType 和 connectionStr 的字段名大小写
        //   4. 如果缓存中dbType是字符串而非枚举，需要转换：Enum.Parse<SqlSugar.DbType>(dbConn.dbType)

        var cacheKey = $"tenant_connection_{tenantId}";
        var tenantCache = _cache.Get<dynamic>(cacheKey);

        if (tenantCache == null)
        {
            // 降级到默认连接
            _logger.LogWarning("租户缓存未命中, TenantId={TenantId}, 使用默认连接", tenantId);
            var defaultConn = _cache.Get<dynamic>("default_connection");
            return (defaultConn.connectionStr, Enum.Parse<DbType>(defaultConn.dbType));
        }

        var connConfig = tenantCache.connectionConfig.ConfigList.First();
        return (connConfig.connectionStr, Enum.Parse<DbType>(connConfig.dbType));
    }
}
```

### 任务2B：FriendlyExceptionFilter 异常日志改造

**目标**：异常日志不受 `[IgnoreLog]` 控制——任何异常都必须记录。读取TraceId，写入Serilog文件日志。

**修改文件**：`Filter/FriendlyExceptionFilter.cs`（或 `LogExceptionHandler.cs`）

```csharp
using Serilog;

namespace YourProject.Filter;

public class FriendlyExceptionFilter : IExceptionFilter
{
    private readonly ILogger<FriendlyExceptionFilter> _logger;

    public FriendlyExceptionFilter(ILogger<FriendlyExceptionFilter> logger)
    {
        _logger = logger;
    }

    public void OnException(ExceptionContext context)
    {
        var traceId = context.HttpContext.Items["TraceId"]?.ToString()
                      ?? TraceContext.TraceId;

        var userId = context.HttpContext.User?.FindFirst("UserId")?.Value ?? "anonymous";
        var requestUrl = context.HttpContext.Request.Path;
        var method = context.HttpContext.Request.Method;

        // ★ 核心：异常日志不受[IgnoreLog]控制
        // 无论接口是否标注了[IgnoreLog]或[LogPolicy.IgnoreAll]，异常都必须记录
        _logger.LogError(context.Exception,
            "未处理异常 | TraceId={TraceId} | {Method} {Url} | UserId={UserId} | Error={ErrorMessage}",
            traceId, method, requestUrl, userId, context.Exception.Message);

        // 返回标准错误响应
        context.Result = new JsonResult(new
        {
            code = 500,
            message = "服务器内部错误",
            traceId = traceId  // 前端可通过此TraceId查询详细日志
        });
        context.ExceptionHandled = true;
    }
}
```

```csharp
};
```

### 任务2D：RequestActionFilter 改造

**目标**：读取TraceId写入日志事件、序列化改为摘要模式、EventBus投递改TryWrite、引入LogPolicy判断。

**修改文件**：`Filter/RequestActionFilter.cs`

```csharp
using System.Threading.Channels;
using YourProject.Attributes;

namespace YourProject.Filter;

public class RequestActionFilter : IActionFilter
{
    private readonly Channel<OperateLogEvent> _logChannel;
    private readonly ILogger<RequestActionFilter> _logger;
    private readonly Stopwatch _stopwatch;

    public RequestActionFilter(
        Channel<OperateLogEvent> logChannel,
        ILogger<RequestActionFilter> logger)
    {
        _logChannel = logChannel;
        _logger = logger;
        _stopwatch = new Stopwatch();
    }

    public void OnActionExecuting(ActionExecutingContext context)
    {
        _stopwatch.Restart();
    }

    public void OnActionExecuted(ActionExecutedContext context)
    {
        _stopwatch.Stop();

        // 读取TraceId
        var traceId = context.HttpContext.Items["TraceId"]?.ToString()
                      ?? TraceContext.TraceId;

        // 读取LogPolicy（从Action方法的特性上获取）
        var policy = LogPolicy.Full; // 默认
        var endpoint = context.HttpContext.GetEndpoint();
        var policyAttr = endpoint?.Metadata.GetMetadata<LogPolicyAttribute>();
        if (policyAttr != null)
        {
            policy = policyAttr.Policy;
        }

        // ★ 检查策略：IgnoreAll则不记录
        if (policy.HasFlag(LogPolicy.IgnoreAll))
            return;

        // ★ 检查策略：Force则强制记录（跳过下面的Channel满判断）
        var isForce = policy.HasFlag(LogPolicy.Force);

        // 序列化请求参数（摘要模式，避免大对象序列化）
        string requestParam = null;
        if (!policy.HasFlag(LogPolicy.IgnoreRequest))
        {
            requestParam = SerializeAsSummary(context.ActionArguments);
        }

        // 序列化响应结果（摘要模式）
        string actionResult = null;
        if (!policy.HasFlag(LogPolicy.IgnoreResponse) && context.Result != null)
        {
            actionResult = SerializeResultAsSummary(context.Result);
        }

        var logEvent = new OperateLogEvent
        {
            TraceId = traceId,
            TenantId = GetTenantId(context.HttpContext),
            UserId = GetUserId(context.HttpContext),
            UserName = GetUserName(context.HttpContext),
            RequestUrl = context.HttpContext.Request.Path,
            RequestParam = requestParam,
            ActionResult = actionResult,
            RequestTime = DateTime.Now,
            ElapsedTime = _stopwatch.ElapsedMilliseconds
        };

        // ★ EventBus投递改为TryWrite + 失败兜底
        if (!_logChannel.Writer.TryWrite(logEvent))
        {
            if (isForce)
            {
                // Force模式下同步写入（阻塞当前请求，但不丢日志）
                _logger.LogWarning(
                    "Channel满但日志为Force模式，同步写入 | TraceId={TraceId} | {Method} {Url}",
                    traceId, context.HttpContext.Request.Method, context.HttpContext.Request.Path);

                // TODO: 如果Force模式频繁触发，说明Channel容量需要调大
                // 临时方案：直接同步调用LogEventSubscriber写数据库
            }
            else
            {
                // ★ 遗漏1修复：TryWrite失败时，通过Serilog文件日志兜底
                // 即使数据库操作日志丢失，文件日志中仍保留TraceId痕迹
                _logger.LogWarning(
                    "操作日志投递失败(Channel满), 已丢弃 | TraceId={TraceId} | {Method} {Url} | UserId={UserId} | Elapsed={Elapsed}ms",
                    traceId, context.HttpContext.Request.Method, context.HttpContext.Request.Path,
                    logEvent.UserId, logEvent.ElapsedTime);
            }
        }
    }

    /// <summary>
    /// 摘要模式序列化：大对象只序列化前200字符 + 类型信息
    /// </summary>
    private string SerializeAsSummary(IDictionary<string, object> args)
    {
        if (args == null || args.Count == 0) return null;

        var summaries = args.Select(kv =>
        {
            var value = kv.Value;
            if (value == null) return $"{kv.Key}=null";

            var json = System.Text.Json.JsonSerializer.Serialize(value);
            if (json.Length > 200)
            {
                // 只保留前200字符 + 截断标记
                return $"{kv.Key}={json[..200]}...(truncated, total {json.Length} chars)";
            }
            return $"{kv.Key}={json}";
        });

        return "{" + string.Join(", ", summaries) + "}";
    }

    private string SerializeResultAsSummary(IActionResult result)
    {
        if (result is JsonResult jsonResult)
        {
            var json = System.Text.Json.JsonSerializer.Serialize(jsonResult.Value);
            if (json.Length > 500)
            {
                return json[..500] + $"...(truncated, total {json.Length} chars)";
            }
            return json;
        }
        return result.GetType().Name;
    }
}
```

### 任务3C：LogDiskGuardService

**目标**：磁盘空间保护，当日志目录所在磁盘剩余空间不足时报警并停止写入。

**新增文件**：`Services/LogDiskGuardService.cs`

```csharp
namespace YourProject.Services;

public class LogDiskGuardService : BackgroundService
{
    private readonly ILogger<LogDiskGuardService> _logger;
    private readonly IConfiguration _cfg;

    // 阈值：剩余5GB时报警，剩余1GB时停止写入
    private const long WarningThresholdBytes = 5L * 1024 * 1024 * 1024;   // 5GB
    private const long CriticalThresholdBytes = 1L * 1024 * 1024 * 1024;  // 1GB

    // 静态标志，供Serilog Sink判断是否继续写入
    public static bool IsDiskCritical { get; private set; }

    public LogDiskGuardService(ILogger<LogDiskGuardService> logger, IConfiguration cfg)
    {
        _logger = logger;
        _cfg = cfg;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                var logDir = _cfg["Logging:File:LogDir"] ?? "logs";
                var driveInfo = new DriveInfo(Path.GetPathRoot(Path.GetFullPath(logDir)));
                var freeBytes = driveInfo.AvailableFreeSpace;

                if (freeBytes < CriticalThresholdBytes)
                {
                    IsDiskCritical = true;
                    _logger.LogCritical(
                        "LOG_DISK_CRITICAL | 剩余空间 {FreeMB}MB | 日志写入已暂停 | 请立即清理磁盘",
                        freeBytes / 1024 / 1024);
                }
                else if (freeBytes < WarningThresholdBytes)
                {
                    IsDiskCritical = false;
                    _logger.LogWarning(
                        "LOG_DISK_WARNING | 剩余空间 {FreeMB}MB | 请及时清理日志文件",
                        freeBytes / 1024 / 1024);
                }
                else
                {
                    IsDiskCritical = false;
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "磁盘空间检测异常");
            }

            await Task.Delay(TimeSpan.FromMinutes(5), stoppingToken);
        }
    }
}
```

```csharp
        // result.OperationLogs = await _db.Queryable<SysLog>()
        //     .Where(x => x.F_TraceId == traceId)
        //     .OrderBy(x => x.F_RequestTime)
        //     .ToListAsync();

    /// GET /api/technical-log/slow-requests?date=2025-01-01&threshold=1000
    /// 查询慢请求日志（从warning文件中过滤）
    /// </summary>
    public async Task<List<TechLogEntry>> GetSlowRequestsAsync(
        DateTime? date, int thresholdMs = 1000)
    {
        var logDir = _cfg["Logging:File:LogDir"] ?? "logs";
        var dateStr = date?.ToString("yyyyMMdd") ?? DateTime.Now.ToString("yyyyMMdd");
        var filePath = Path.Combine(logDir, $"warning-{dateStr}.json");

        if (!File.Exists(filePath))
            return new List<TechLogEntry>();

        var entries = await ReadLogFileAsync(filePath);
        return entries
            .Where(e => e.Message != null && e.Message.Contains("Slow SQL"))
            .ToList();
    }

    /// <summary>
    /// 流式读取日志文件，支持FileShare.ReadWrite（读取正在写入的文件）
    /// </summary>
    private async Task<List<TechLogEntry>> ReadLogFileAsync(
        string filePath, string level = null, string traceId = null)
    {
        var entries = new List<TechLogEntry>();

        using var stream = new FileStream(
            filePath, FileMode.Open, FileAccess.Read, FileShare.ReadWrite);
        using var reader = new StreamReader(stream);

        string line;
        while ((line = await reader.ReadLineAsync()) != null)
        {
            if (string.IsNullOrWhiteSpace(line)) continue;

            try
            {
                var entry = JsonSerializer.Deserialize<TechLogEntry>(line);
                if (entry == null) continue;

                // 过滤条件
                if (!string.IsNullOrEmpty(level) && !string.Equals(entry.Level, level, StringComparison.OrdinalIgnoreCase))
                    continue;
                if (!string.IsNullOrEmpty(traceId) && entry.TraceId != traceId)
                    continue;

                entries.Add(entry);
            }
            catch (JsonException)
            {
                // ⚠️ 正常情况：最后一行可能正在写入，JSON不完整，跳过即可
                // 异常情况：格式确实不对的日志行，记录Debug级别日志
                _logger.LogDebug("Skipped malformed log line in {File}", filePath);
                continue;
            }
        }

        return entries;
    }
}
```

```csharp
var entries = entriesField.GetValue(cache);
var json = System.Text.Json.JsonSerializer.Serialize(entries, new JsonSerializerOptions { WriteIndented = true });
Console.WriteLine(json);

// 将输出的JSON格式化后贴到工位，逐字段对照ResolveConnectionConfig代码
```

## 八、Serilog格式决策（最终版）

### 决策结果

| 场景                                  | 格式                                 | 理由                                              |
| ------------------------------------- | ------------------------------------ | ------------------------------------------------- |
| **默认（A/D类客户，前端直接查文件）** | `JsonFormatter(renderMessage: true)` | 字段名直观（Timestamp/Message/Level），前端零适配 |
| **对接Seq的B/C类客户**                | `CompactJsonFormatter`               | Seq原生支持，存储减30%                            |

### 实现方式

```csharp
// 根据部署配置选择格式，不同时写两份文件
var fileFormatter = cfg["Logging:Seq:Enabled"] == "true"
    ? new CompactJsonFormatter() as ITextFormatter
    : new JsonFormatter(renderMessage: true);

// 所有File Sink统一使用同一个formatter
.WriteTo.File(
    formatter: fileFormatter,
    path: Path.Combine(logDir, "error-.json"),
    rollingInterval: RollingInterval.Day,
    restrictedToMinimumLevel: LogEventLevel.Error,
    retainedFileCountLimit: 30,
    fileSizeLimitBytes: 50 * 1024 * 1024)
```

### 为什么不用两个File Sink同时写两种格式

```
❌ 两份文件 = 两倍IO + 两倍磁盘占用
❌ 前端解析器需要适配两种格式
✅ 客户类型在部署时就确定，不需要运行时切换
✅ 配置文件一个字段控制：Logging:Seq:Enabled = true/false
```
