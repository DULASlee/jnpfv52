> **注意：** OA 模块（JNPF.OA.API.Entry）在本项目中未启用。如需激活，请先经架构师评估与现有 IoT/MES 模块的集成影响。

### 7. 架构文档 5 条强制规则 — 优先执行

**架构师分析：**

老板判断**极为准确**。这5条规则是 AI 编程效率和正确性的核心保障。

**执行指令：**

将 ARCHITECTURE_DOC_RULES.md 中的5条规则**直接内联到 CLAUDE.md** 中，措辞必须为命令式。格式如下：

```markdown
## 架构文档强制规则（MUST COMPLY）

以下规则对所有 AI 辅助代码生成和架构决策具有强制约束力：

### Rule 1: 模块边界不可逾越
**不得**在代码中引入跨模块的直接依赖调用。跨模块交互必须通过接口定义层（Interface）进行。

### Rule 2: 新增功能必须声明模块归属
任何新增的 Service、Entity、DTO **必须**明确声明其归属模块。不允许创建"通用"或"临时"的游离代码。

### Rule 3: API 入口必须遵循 DynamicApiController 约定
**不得**手动创建 Controller。所有 API **必须**通过 Service 方法自动暴露。

### Rule 4: 数据库变更必须通过 Migration 管理
**不得**手动执行 DDL。所有表结构变更**必须**通过 SqlSugar CodeFirst 或 Migration 脚本管理。

### Rule 5: 文档与代码同步更新
修改任何架构相关代码后，**必须**同步更新对应的架构文档。不得出现文档与代码不一致的情况。
```

> **注意：** 以上5条规则的具体措辞需要工程师从 ARCHITECTURE_DOC_RULES.md 中提取原文，我（架构师）在最终审核时确认措辞准确性。

**完成标准：** CLAUDE.md 中有完整的5条命令式规则，措辞经架构师确认。

### 10. 移除冗余 — 明确方案

**架构师深入分析：**

这是最需要仔细处理的一项。我分析了三种可能的情况：

#### 情况分析

| 情况                                   | 现状描述             | 处理方案                         |
| -------------------------------------- | -------------------- | -------------------------------- |
| **A: CLAUDE.md 和 AGENTS.md 完全重复** | 大段内容完全相同     | 消除 AGENTS.md，只保留 CLAUDE.md |
| **B: 两者有重叠但各有独占内容**        | 约 60-70% 重叠       | 提取共享内容，保留各自独占内容   |
| **C: 两者职责不同但表述相似**          | 表述相似但上下文不同 | 保持独立，仅消除逐字重复         |

#### 判定方法

工程师执行以下检查步骤：

```
Step 1: 文本对比
  - 使用 diff 工具对比 CLAUDE.md 和 AGENTS.md
  - 标记：完全相同段落 / 语义相同但措辞不同 / 独占内容

Step 2: 职责判定
  - CLAUDE.md 的职责：给 claude.ai/code 运行时的项目上下文
  - AGENTS.md 的职责：给 GitHub Copilot Agents 等工具的项目上下文
  - 如果两者服务于同一运行时 → 合并为一个文件
  - 如果服务于不同运行时 → 保留独立文件，消除重复段落

Step 3: 股权式治理（引用式共享）
  - 对于必须在两个文件中都出现的信息，采用引用方式：
    - 主文件写完整内容
    - 副文件写 "参见 CLAUDE.md 第 X 节"
```

#### 最终建议（我的判断）

基于 JNPF V5.2 项目场景，**我倾向于情况 B，执行以下方案：**

```markdown
## 建议文件结构

CLAUDE.md          ← 主文件，包含完整的项目上下文（当前改进版）
AGENTS.md          ← 精简版，仅包含：
                      1. 运行时标识声明（区别于 claude.ai/code）
                      2. 指向 CLAUDE.md 的引用："完整项目上下文参见 CLAUDE.md"
                      3. AGENTS.md 独有的差异化指令（如有）
SHARED_RULES.md    ← （可选）如果存在大量跨运行时共享规则，抽取至此文件
```

**但最终方案取决于 AGENTS.md 是否服务于不同的运行时。** 工程师需先完成 Step 1 的文本对比，提交对比结果给我，我再给出最终裁定。

**完成标准：**
- 消除所有逐字重复
- 每个文件有明确且独立的职责
- 无维护时需要同步更新多处的情况
