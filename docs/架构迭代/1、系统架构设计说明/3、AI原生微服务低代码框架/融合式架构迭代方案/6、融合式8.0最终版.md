### ADR-001：ISqlSugarClient 注册方式

**决策：** 强制 Singleton + CopyNew()，不可选 Scoped。

**理由：** SqlSugarScope 官方设计为单例，内部通过 AsyncLocal 实现上下文隔离。改为 Scoped 会导致：连接池无法复用、多租户 GetConnectionScope 失效、构造函数重复执行导致内存暴涨。

---

### ADR-002：DataExecuting 实现策略

**决策：** 启动时一次性组装完整委托，运行时通过 `TenantContext.Current` 静态访问点读取当前租户/系统信息。禁止运行时动态修改委托链，禁止使用 Service Locator。

**前置验证：** 阶段 0 任务 0.6 验证 DataExecuting 赋值行为（`=` vs `+=`）以及 CopyNew 是否继承 AOP。

---

### ADR-003：TenantContext 解析方式

**决策：** 同步属性读取 + AsyncLocal 传播 + 中间件预热 + 静态访问点。禁止异步构造函数，禁止 Service Locator。

**TenantContext.Current 设计：**
```
TenantContext 类内部：
  private static readonly AsyncLocal<TenantInfo> _current = new();
  
  // 静态访问点：供 DataExecuting 等启动时编译的委托使用
  public static TenantInfo Current => _current.Value;
  
  // 设置当前租户（中间件/入口点调用）
  public static IDisposable SetCurrent(TenantInfo info)
  {
      var previous = _current.Value;
      _current.Value = info;
      return new DisposableAction(() => _current.Value = previous);
  }
  
  // 清除当前租户（中间件 finally 中调用，防线程池污染）
  public static void ClearCurrent()
  {
      _current.Value = null;
  }
```

**关键约束：** `TenantContext.Current` 仅在 DataExecuting 等"无法注入 Scoped 服务"的场景中使用。业务代码应通过构造函数注入 `ITenantContext`。

### ADR-008：Outbox 投递策略与多实例安全

**决策：**

**投递唤醒：** Channel<T> 信号唤醒 + 30 秒兜底轮询。**进程退出时排空 Channel（ADR-015）。**

**多实例安全：** `SqlSugarEventOutboxStore.GetPendingAsync()` 使用数据库原生行锁：

### ADR-012：Updateable/Deleteable 的全局租户保护（v8.0 增强版）

**决策：** SqlSugar 的 `QueryFilter.AddTableFilter<T>()` 仅对 `Queryable<T>` 生效，**不对 `Updateable<T>` 和 `Deleteable<T>` 生效**。因此仅靠 QueryFilter 无法保护写操作，必须在 Repository 层面进行三层防护。

**三层防护体系：**

```
第一层：Repository 基类方法覆写（强制防线）
  SqlSugarRepository<T> 重写 UpdateAsync / DeleteAsync / InsertAsync：
    - 检查实体是否实现 ITenantFilter
    - 如果已启用多租户且当前非默认租户：
      → Update/Delete：自动附加 WHERE TenantId = @currentTenantId
      → Insert：自动设置实体的 TenantId 属性
    - 记录 WARNING 日志（提示迁移至 TenantSafe 方法）

第二层：TenantSafe 扩展方法（显式安全入口）
  TenantSafeUpdateAsync / TenantSafeDeleteAsync：
    - 显式附加租户条件
    - 新模板生成的代码使用此方法

第三层：模板更新（增量安全）
  Service.cs.vm 模板更新为 TenantSafeUpdateAsync
    - 未来生成的代码默认安全
```

**核心实现（Repository 基类覆写）：**
```
public override async Task<bool> UpdateAsync(TEntity entity)
{
    if (_tenantContext.IsMultiTenant && !_tenantContext.IsDefaultTenant()
        && typeof(ITenantFilter).IsAssignableFrom(typeof(TEntity)))
    {
        // 自动附加租户条件到 WHERE 子句
        var tenantId = _tenantContext.TenantId;
        // SqlSugar 的 Updateable 支持 .Where() 附加条件
        // 使用 ISqlSugarClient 的 Updateable<T>(entity).Where(it => it.TenantId == tenantId).ExecuteCommandAsync()
        
        Log.Warning("UpdateAsync called without explicit tenant filter on {EntityType}. " +
            "Auto-applied tenant condition. Migrate to TenantSafeUpdateAsync.", typeof(TEntity).Name);
    }
    return await base.UpdateAsync(entity);
}
```

**阶段 0 新增验证（任务 0.11）：** 验证 SqlSugar 的 `Updateable<T>(entity).Where(it => it.TenantId == tenantId).ExecuteCommandAsync()` 是否能正确附加 WHERE 条件。如果 SqlSugar 版本不支持 Updateable 上的 Where 条件，备选方案是在 AOP 的 `OnLogExecuting` 中检测 UPDATE/DELETE SQL 是否包含 TenantId 条件并抛出异常。

### ADR-013：非 HTTP 入口的租户上下文传播（v8.0 新增）

**决策：** AsyncLocal 随 ExecutionContext 流动，但在显式 `Task.Run` 或 `new Thread` 场景下可能丢失。低代码平台大量依赖 EventBus 消费者和定时任务等非 HTTP 执行链路。必须在所有非 HTTP 入口设置强制性拦截器，而非依赖业务开发者手动调用。

**三种入口的传播机制：**

```
入口 1：HTTP 请求
  → TenantMiddleware（try/finally + ClearScope，ADR-003）
  → SetFromHttpContext → AsyncLocal 设置

入口 2：EventBus 消费者
  → EventBusPipelineFilter（新增拦截器）
  → 从 EventSource Payload 提取 TenantId
  → SetExplicit → AsyncLocal 设置
  → handler 执行后 finally 清除

入口 3：定时任务
  → JobExecutionFilter（新增拦截器）
  → 从 Job 元数据读取 TenantId
  → SetExplicit → AsyncLocal 设置
  → job 执行后 finally 清除
```

**强制性约束：**
- EventBus 管道中必须插入租户传播 Filter，所有 EventSubscribe 处理器自动获得租户上下文
- 定时任务调度器必须在 Job 元数据中携带 TenantId，执行前自动恢复上下文
- 如果 TenantId 为空，降级为默认租户（不抛异常，但记录 WARNING）

### ADR-014：Repository 的 IDisposable 保障（v8.0 新增）

**决策：** CopyNew() 产生的临时上下文必须在 Repository 生命周期结束时正确释放。

**设计：**
```
public class SqlSugarRepository<TEntity> : SimpleClient<TEntity>, IDisposable
{
    private readonly ISqlSugarClient _rootScope; // Singleton 父实例引用
    
    public SqlSugarRepository(ISqlSugarClient context, ITenantContext tenantContext, ...)
    {
        _rootScope = context; // 保存 Singleton 引用
        base.Context = ((SqlSugarScope)context).CopyNew(); // 创建临时副本
        // ...
    }
    
    public void Dispose()
    {
        // 仅释放 CopyNew 的临时副本
        // SqlSugarScope 内部机制保证不会关闭 Singleton 的底层物理连接
        if (base.Context != null && base.Context != _rootScope)
        {
            base.Context.Dispose();
        }
    }
}
```

**DI 生命周期保障：** Repository 是 Scoped 的，ASP.NET Core 框架在请求结束时自动调用 Dispose。对于非 HTTP 场景（EventBus/定时任务），拦截器负责创建 Scope 并在完成后释放。

### ADR-015：Outbox Dispatcher 优雅停机（v8.0 新增）

**决策：** 进程退出（SIGTERM / K8s Pod 缩容 / 发版重启）时，内存 Channel 中尚未落库/投递的事件会丢失。必须在 BackgroundService 的 StopAsync 中强制排空。

**设计：**
```
public override async Task StopAsync(CancellationToken cancellationToken)
{
    _logger.LogInformation("OutboxDispatcher stopping, draining pending messages...");
    
    // 等待 Channel 中的消息被处理完（最多等待 DrainTimeout）
    var drainTimeout = TimeSpan.FromSeconds(30);
    var deadline = DateTime.UtcNow.Add(drainTimeout);
    
    while (DateTime.UtcNow < deadline && !_channel.Reader.Completion.IsCompleted)
    {
        if (_channel.Reader.TryRead(out var signal))
        {
            await ProcessSignalAsync(signal);
        }
        else
        {
            await Task.Delay(100, cancellationToken);
        }
    }
    
    // 执行最后一轮批量投递
    await FlushPendingAsync();
    
    _logger.LogInformation("OutboxDispatcher drained successfully.");
    await base.StopAsync(cancellationToken);
}
```

### 任务 0.10 Outbox 事务原子性 PoC（v7.0 前移，清言修正令 3）

**目的：** 在手术开始前确认 SqlSugar 跨表事务可行性。如果不可行，必须将 Outbox 设计从"强事务模式"调整为"最终一致性补偿模式"。

**执行内容：**

```
PoC 1：SqlSugar 单数据库事务

  {
      // 步骤 1：Insert 业务表
      await db.Insertable(businessEntity).ExecuteCommandAsync();
      
      // 步骤 2：Insert Outbox 表
      await db.Insertable(outboxMessage).ExecuteCommandAsync();
      
      // 验证：两步是否在同一事务中
      tran.CommitTran();
  }
  // 验证：Rollback 时两步是否同时回滚
```

```
PoC 2：CopyNew 后的事务隔离
  var parent = GetSingletonInstance();
  var child = parent.CopyNew();
  
  using (var tran = child.UseTran())

/// <summary>
/// EventBus 管道拦截器：在事件处理器执行前恢复租户上下文，执行后清除。
/// ⚠️ 铁律：所有 EventSubscribe 处理器自动获得租户上下文，无需手动调用。
/// </summary>
public class TenantPropagationFilter : IEventFilter
{
    private readonly ITenantContext _tenantContext;
    
    public async Task OnActionAsync(EventHandlerExecutingContext context, EventHandlerInvoker next)
    {
        // 从 EventSource 中提取 TenantId
        var source = context.Source;
        var tenantId = source?.TenantId 
            ?? source?.Payload?.GetType().GetProperty("TenantId")?.GetValue(source.Payload)?.ToString();
        
        if (!string.IsNullOrEmpty(tenantId))
        {
            _tenantContext.SetExplicit(tenantId);
        }
        
        try
        {
            await next(context);
        }
        finally
        {
            // ⚠️ 必须清除，防止 AsyncLocal 泄漏到后续处理
            _tenantContext.ClearScope();
        }
    }
}

```
public class SqlSugarRepository<TEntity> : SimpleClient<TEntity>, 
    ISqlSugarRepository<TEntity>, IDisposable
{
    private readonly ISqlSugarClient _rootScope;
    private readonly ITenantContext _tenantContext;
    private readonly ITenantIsolationStrategy _strategy;
    
    public SqlSugarRepository(ISqlSugarClient context, ITenantContext tenantContext, 
        ITenantIsolationStrategy strategy)
    {
        _rootScope = context;
        _tenantContext = tenantContext;
        _strategy = strategy;
        
        // 1. CopyNew 获取隔离上下文
        base.Context = ((SqlSugarScope)context).CopyNew();
        
        // 2. 多租户连接切换
        if (tenantContext.IsMultiTenant && !tenantContext.IsDefaultTenant())
        {
            var connectionInfo = tenantContext.ConnectionInfo;
            if (connectionInfo == null)
            {
                Log.Warning("Tenant connection not found for {TenantId}, fallback", 
                    tenantContext.TenantId);
            }
            else
            {
                if (!base.Context.AsTenant().IsAnyConnection(connectionInfo.ConfigId))
                    base.Context.AsTenant().AddConnection(
                        strategy.ConfigureConnection(connectionInfo));
                
                base.Context = base.Context.AsTenant()
                    .GetConnectionScope(connectionInfo.ConfigId);
                
                if (tenantContext.IsolationType == 1)
                    strategy.ApplyQueryFilter(base.Context, tenantContext);
            }
        }
        
        // 3. 系统过滤
        if (tenantContext.IsMultiSystem 
            && !tenantContext.ShouldSkipSystemFilter
            && !string.IsNullOrEmpty(tenantContext.SystemId))
        {
            base.Context.QueryFilter.AddTableFilter<IZxSystemFilter>(
                it => it.ZxSystemId == tenantContext.SystemId);
        }
        
        // 4. 情况 C 的 AOP 重注册（仅在需要时）
        // SqlSugarConfigureExtensions.ApplyDataExecuting(base.Context);
    }
    
    // === ADR-012 三层防护：Repository 基类方法覆写 ===
    
    public override async Task<bool> UpdateAsync(TEntity entity)
    {
        if (_tenantContext.IsMultiTenant && !_tenantContext.IsDefaultTenant()
            && typeof(ITenantFilter).IsAssignableFrom(typeof(TEntity)))
        {
            Log.Warning("UpdateAsync on {Entity} without explicit tenant filter. " +
                "Auto-applied. Migrate to TenantSafeUpdateAsync.", typeof(TEntity).Name);
            
            // 根据任务 0.11 验证结果选择实现方式
            // 方式 1（如果 Updateable 支持 .Where）：
            //   return await base.Context.Updateable(entity)
            //       .Where(it => ((ITenantFilter)it).TenantId == _tenantContext.TenantId)
            //       .ExecuteCommandAsync() > 0;
            // 方式 2（如果仅支持基类方式）：
            //   在 SQL 生成层面附加 WHERE
        }
        return await base.UpdateAsync(entity);
    }
    
    public override async Task<bool> DeleteAsync(TEntity entity)
    {
        if (_tenantContext.IsMultiTenant && !_tenantContext.IsDefaultTenant()
            && typeof(ITenantFilter).IsAssignableFrom(typeof(TEntity)))
        {
            Log.Warning("DeleteAsync on {Entity} without explicit tenant filter. " +
                "Auto-applied. Migrate to TenantSafeDeleteAsync.", typeof(TEntity).Name);
        }
        return await base.DeleteAsync(entity);
    }
    
    public override async Task<bool> InsertAsync(TEntity entity)
    {
        if (_tenantContext.IsMultiTenant && !_tenantContext.IsDefaultTenant()
            && typeof(ITenantFilter).IsAssignableFrom(typeof(TEntity)))
        {
            // 自动设置 TenantId
            ((ITenantFilter)entity).TenantId = _tenantContext.TenantId;
        }
        return await base.InsertAsync(entity);
    }
    
    // === ADR-014：IDisposable 实现 ===
    public void Dispose()
    {
        // 仅释放 CopyNew 的临时副本
        // SqlSugarScope 内部保证不关闭 Singleton 的物理连接
        if (base.Context != null && base.Context != _rootScope)
        {
            base.Context.Dispose();
        }
    }
}

public async Task<IList<EventOutboxMessage>> GetPendingAsync(int batchSize)
{
    var dbType = _db.CurrentConnectionConfig.DbType;
    string sql = dbType switch
    {
        DbType.SqlServer => $@"
            SELECT TOP({batchSize}) * FROM EventOutboxMessage 
            WITH (UPDLOCK, READPAST)
            WHERE Status IN (0, 3) AND RetryCount < MaxRetryCount
            ORDER BY CreatedAt",
        DbType.MySql => $@"
            SELECT * FROM EventOutboxMessage 
            WHERE Status IN (0, 3) AND RetryCount < MaxRetryCount
            ORDER BY CreatedAt LIMIT {batchSize} FOR UPDATE SKIP LOCKED",
        DbType.PostgreSQL => $@"
            SELECT * FROM EventOutboxMessage 
            WHERE Status IN (0, 3) AND RetryCount < MaxRetryCount
            ORDER BY CreatedAt LIMIT {batchSize} FOR UPDATE SKIP LOCKED",
        _ => throw new NotSupportedException(
            $"DbType {dbType} not supported for Outbox row locking")
    };
    return await _db.Ado.SqlQueryAsync<EventOutboxMessage>(sql);
}

`EventOutboxDispatcher.cs`（千问补丁 2 + ADR-015：优雅停机）：
```
public class EventOutboxDispatcher : BackgroundService
{
    private readonly Channel<bool> _signalChannel = Channel.CreateBounded<bool>(1);
    private readonly IEventOutboxStore _outboxStore;
    private readonly IServiceProvider _serviceProvider;
    private readonly ILogger<EventOutboxDispatcher> _logger;
    
    public void NotifyNewMessage()
    {
        _signalChannel.Writer.TryWrite(true);
    }
    
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                // 等待信号或 30 秒超时
                var signalTask = _signalChannel.Reader.WaitToReadAsync(stoppingToken).AsTask();
                var delayTask = Task.Delay(TimeSpan.FromSeconds(30), stoppingToken);
                await Task.WhenAny(signalTask, delayTask);
                
                // 批量处理
                await FlushPendingAsync(stoppingToken);
            }
            catch (OperationCanceledException) when (stoppingToken.IsCancellationRequested)
            {
                break;
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "OutboxDispatcher error in main loop");
                await Task.Delay(5000, stoppingToken);
            }
        }
    }
    
    private async Task FlushPendingAsync(CancellationToken ct)
    {
        var messages = await _outboxStore.GetPendingAsync(100);
        foreach (var msg in messages)
        {
            if (ct.IsCancellationRequested) break;
            
            try
            {
                using var scope = _serviceProvider.CreateScope();
                var eventBus = scope.ServiceProvider.GetRequiredService<IEventPublisher>();
                
                // 通过 Polly 投递
                await _retryHandler.ExecuteAsync(async () =>
                {
                    await eventBus.PublishAsync(msg.EventName, 
                        JsonConvert.DeserializeObject(msg.EventPayload));
                });
                
                await _outboxStore.MarkCompletedAsync(msg.Id);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Outbox message {Id} delivery failed", msg.Id);
                await _outboxStore.MarkFailedAsync(msg.Id, ex.Message);
            }
        }
    }
    
    // ⚠️ ADR-015 + 千问补丁 2：优雅停机，排空 Channel
    public override async Task StopAsync(CancellationToken cancellationToken)
    {
        _logger.LogInformation("OutboxDispatcher stopping, draining...");
        
        // 关闭信号 Channel
        _signalChannel.Writer.Complete();
        
        // 等待 Channel 中剩余信号被处理
        await Task.Delay(1000, cancellationToken);
        
        // 执行最后一轮批量投递
        try
        {
            await FlushPendingAsync(cancellationToken);
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "Outbox drain encountered error during shutdown");
        }
        
        _logger.LogInformation("OutboxDispatcher drained.");
        await base.StopAsync(cancellationToken);
    }
}
```
