## T6：CancellationToken 覆盖率提升（核心模块）

### 目标

将 Systems、OAuth、WorkFlow 三个核心模块的 CancellationToken 覆盖率从 ~18% 提升至 70%+。

### 现状分析

```
总 async 方法：1351 个
当前有 CancellationToken：244 个（18%）
目标模块：JNPF.Systems + JNPF.OAuth + JNPF.WorkFlow
预估修改方法数：~60 个
```

### 修改范围

| 模块 | 典型文件 | 预计方法数 | 优先级 |
|------|----------|-----------|--------|
| JNPF.Systems | UsersService.cs, DepartmentService.cs, RoleService.cs, OrganizeService.cs, MenuService.cs, DictionaryService.cs | ~35 | P0 |
| JNPF.OAuth | OAuthService.cs | ~5 | P0 |
| JNPF.WorkFlow | FlowTaskService.cs, FlowTemplateService.cs, FlowDelegateService.cs | ~20 | P1 |

### 变更模式（三种安全模式，均不影响调用方）

**模式 A：方法签名追加参数（最常见）**

```csharp
// 改前
public async Task<PageResult<UserOutput>> GetPageList(PageInput input)
{
    return await _repository.GetPageListAsync(input);
}

// 改后 — 仅追加参数，有默认值，所有调用方无需修改
public async Task<PageResult<UserOutput>> GetPageList(PageInput input, CancellationToken cancellationToken = default)
{
    return await _repository.GetPageListAsync(input, cancellationToken);
}
```

**模式 B：Repository 查询传递 CancellationToken**

```csharp
// 改前
var entity = await _repository.GetSingleAsync(x => x.Id == id);

// 改后
var entity = await _repository.GetSingleAsync(x => x.Id == id, cancellationToken);
```

**模式 C：Insertable/Updateable 传递 CancellationToken**

```csharp
// 改前
await _repository.Context.Insertable(entity).ExecuteCommandAsync();

// 改后
await _repository.Context.Insertable(entity).ExecuteCommandAsync(cancellationToken);
```

### 执行策略

1. **逐文件推进**，每个文件修改后执行 `dotnet build` 验证
2. **不修改接口定义**（IDynamicApiController 接口方法不暴露 CancellationToken）
3. **不修改调用方**（默认参数向后兼容）
4. **DynamicApiController 自动忽略 CancellationToken 参数**（框架已支持）

- 仅追加方法参数（带默认值 `= default`），不修改方法体核心逻辑

## T7：租户写操作安全扩展方法

### 目标

新增租户安全的写操作扩展方法，为后续逐模块迁移提供基础。

### 新增文件

| 文件 | 说明 |
|------|------|
| `backend/framework/JNPF.Extras.DatabaseAccessor.SqlSugar/Extensions/SqlSugarTenantSafeExtensions.cs` | 租户安全写操作扩展方法 |

### 代码实现

```csharp
// SqlSugarTenantSafeExtensions.cs
using JNPF.Extras.DatabaseAccessor.SqlSugar.Models;
using SqlSugar;
using System.Linq.Expressions;

namespace SqlSugar;

/// <summary>
/// 租户安全写操作扩展方法
/// 解决 Trap 8：Updateable/Deleteable 不自动附加 TenantId 的问题
/// </summary>
public static class SqlSugarTenantSafeExtensions
{
    /// <summary>
    /// 租户安全更新 — 自动附加 TenantId 条件
    /// </summary>
    /// <typeparam name="TEntity">实体类型（必须实现 ITenantFilter）</typeparam>
    /// <param name="context">SqlSugar 客户端</param>
    /// <param name="entity">要更新的实体</param>
    /// <param name="tenantId">当前租户 ID</param>
    /// <param name="additionalWhere">额外的 WHERE 条件（可选）</param>
    /// <returns>受影响行数</returns>
    public static async Task<int> TenantSafeUpdateAsync<TEntity>(
        this ISqlSugarClient context,
        TEntity entity,
        string tenantId,
        Expression<Func<TEntity, bool>>? additionalWhere = null)
        where TEntity : class, new()
    {
        var updateable = context.Updateable(entity)
            .Where(x => ((ITenantFilter)x).TenantId == tenantId);

        if (additionalWhere != null)
            updateable = updateable.Where(additionalWhere);

        return await updateable.ExecuteCommandAsync();
    }

    /// <summary>
    /// 租户安全批量更新 — 自动附加 TenantId 条件
    /// </summary>
    public static async Task<int> TenantSafeUpdateAsync<TEntity>(
        this ISqlSugarClient context,
        List<TEntity> entities,
        string tenantId)
        where TEntity : class, new()
    {
        return await context.Updateable(entities)
            .Where(x => ((ITenantFilter)x).TenantId == tenantId)
            .ExecuteCommandAsync();
    }

    /// <summary>
    /// 租户安全删除 — 自动附加 TenantId 条件
    /// </summary>
    public static async Task<int> TenantSafeDeleteAsync<TEntity>(
        this ISqlSugarClient context,
        Expression<Func<TEntity, bool>> where,
        string tenantId)
        where TEntity : class, new()
    {
        return await context.Deleteable<TEntity>()
            .Where(where)
            .Where(x => ((ITenantFilter)x).TenantId == tenantId)
            .ExecuteCommandAsync();
    }

    /// <summary>
    /// 租户安全逻辑删除 — 自动附加 TenantId 条件，设置 DeleteMark = 1
    /// </summary>
    public static async Task<int> TenantSafeSoftDeleteAsync<TEntity>(
        this ISqlSugarClient context,
        Expression<Func<TEntity, bool>> where,
        string tenantId)
        where TEntity : class, new()
    {
        return await context.Updateable<TEntity>()
            .SetColumns(x => new TEntity { /* DeleteMark = 1 */ })
            .Where(where)
            .Where(x => ((ITenantFilter)x).TenantId == tenantId)
            .ExecuteCommandAsync();
    }
}
```

### 使用方式（新代码应使用，旧代码逐步迁移）

```csharp
// 改前 — 危险：可能更新所有租户数据
await _repository.Context.Updateable(entity).ExecuteCommandAsync();

// 改后 — 安全：自动附加 TenantId 条件
await _repository.Context.TenantSafeUpdateAsync(entity, _userManager.TenantId);
```

## T9：JWT 安全加固

### 目标

密钥从环境变量读取，支持 Token 主动撤销。

### 修改文件

| 文件 | 操作 | 说明 |
|------|------|------|

| `backend/application/JNPF.API.Entry/Handlers/JwtHandler.cs` | 修改 | 添加 Token 黑名单检查 |

### 代码变更

**变更 1：签名密钥环境变量优先**

```csharp
// JWTEncryption.cs — 在获取签名密钥的位置修改
// 改前
var signingKey = App.GetConfig<string>("JWTSettings:IssuerSigningKey");

// 改后 — 环境变量优先，回退到配置文件
var signingKey = Environment.GetEnvironmentVariable("JNPF_JWT_SECRET")
    ?? App.GetConfig<string>("JWTSettings:IssuerSigningKey");
```

> 注：此变更不影响配置文件读取。如果环境变量未设置，行为与当前完全一致。

**变更 2：Token 黑名单检查（可选，仅在需要主动撤销时触发）**

```csharp
// JwtHandler.cs — 在 HandleAsync 方法中添加黑名单检查
public override async Task HandleAsync(AuthorizationHandlerContext context)
{
    var httpContext = context.GetCurrentHttpContext();
    var token = httpContext.GetToken();

    // 检查 Token 是否在黑名单中（密码修改/用户禁用后主动撤销）
    if (!string.IsNullOrEmpty(token))
    {
        var jti = JWTEncryption.GetJwtClaim(token, JwtRegisteredClaimNames.Jti);
        if (!string.IsNullOrEmpty(jti))
        {
            var cache = httpContext.RequestServices.GetService<ICache>();
            if (cache != null && await cache.ExistsAsync($"BLACKLIST_TOKEN:{jti}"))
            {
                context.Fail();
                httpContext.SignoutToSwagger();
                return;
            }
        }
    }

    // 原有逻辑不变
    if (JWTEncryption.AutoRefreshToken(context, httpContext,
        App.GetOptions<JWTSettingsOptions>().ExpiredTime))
    {
        await AuthorizeHandleAsync(context);
    }
    else
    {
        context.Fail();
        httpContext.SignoutToSwagger();
    }
}
```

**变更 3：Token 撤销 API（供密码修改等场景调用）**

```csharp
// 新增方法：在密码修改成功后调用
public static async Task RevokeCurrentTokenAsync(HttpContext httpContext)
{
    var token = httpContext.GetToken();
    if (string.IsNullOrEmpty(token)) return;

    var jti = JWTEncryption.GetJwtClaim(token, JwtRegisteredClaimNames.Jti);
    if (string.IsNullOrEmpty(jti)) return;

    var cache = httpContext.RequestServices.GetService<ICache>();
    if (cache != null)
    {
        // 黑名单有效期 = Token 剩余有效期（最长 24 小时）
        await cache.SetAsync($"BLACKLIST_TOKEN:{jti}", "revoked", TimeSpan.FromHours(24));
    }
}
```

```csharp
// FriendlyExceptionFilter.cs — 在生成异常响应的位置追加 TraceId
```
