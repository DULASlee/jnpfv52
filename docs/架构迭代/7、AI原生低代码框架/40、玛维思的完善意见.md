## 5.3 行业最佳实践吸收建议

### 必须吸收的 4 项

1. **AI Agent 编排框架**(ReAct Loop)
   - v7.7 的 AgentIR 是"配置",缺少"运行时"——ReAct 循环 + 工具调用
   - 必须有 AgentRuntimeOrchestrator
   
2. **多 Agent 协同**(Planner/Executor/Reviewer)
   - 企业专家(Planner)→ 调度岗位 Agent(Executor)→ 业务专家(Reviewer)
   - 必须有 AgentCoordinator

3. **数字员工架构**(数字分身)
   - 岗位专家的目标是"数字员工"
   - 数字员工 = Persona(人设) + Memory(记忆) + Skills(技能) + Knowledge(知识)
   - 必须有 DigitalEmployee 抽象

4. **LLM 评估体系**
   - 准确率/召回率(LLM-as-Judge)
   - 延迟 P50/P95/P99
   - 成本(每租户月 Token 上限)
   - 必须有 EvalSet + 自动化评估脚本

### 强烈建议吸收的 4 项

5. **Hybrid RAG** — 图 + 向量 + 关键词三层
6. **Prompt 工程规范** — Few-Shot 库 + CoT 模板 + ReAct
7. **数据脱敏** — PII 检测 + 敏感字段脱敏 + LLM 输入清洗
8. **企业知识接入** — 文档解析 + 表格识别(为 R3-S1 KnowledgeIR 服务)
