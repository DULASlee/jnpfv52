### 问题一：如何保证AI生成系统的企业级一致性与水准？

你的担心太对了。让一个没有约束的AI去设计系统，它今天可能给你一个优雅的微服务架构，明天就变成一个大单体，后天又全上无服务器。风格的混乱是表象，更深层的恐惧是**架构的混乱、技术债务的不可控、以及维护噩梦的开始。**

我们的解决方案，不是给AI更细的镣铐，而是给它一个**可以自由发挥，但边界绝对清晰的“企业级沙箱”**。这个沙箱，我们称之为 **“企业架构基准（Enterprise Architecture Baseline, EAB）”**。

这不是清言方案里的“契约库”，那是底线的强制约束。EAB是更高维度的、**可定制、可进化的架构宪法**。

**EAB的核心构成：**

1.  **强制性的技术选型快照**：
    *   平台出厂就内置一份由你们（人类专家）精心维护的、经过严格验证的**推荐技术栈清单与版本矩阵**。例如：“微服务框架：JNPF-Cloud v3.2；前端：Vue3.4 + Ant Design Vue 4.0；消息队列：RabbitMQ 3.12；数据库：PostgreSQL 16 + TimescaleDB...”。
    *   AI在进行架构设计时，**必须从这个清单里选择和组合**。它可以建议：“我建议引入Redis Stack 7.2来支撑排程模块的实时计算。”但你不能自行决定用Hazelcast。这个建议会提交给你审核，一旦通过，新的组件就会被你正式加入到EAB中，成为未来的可选项。**这样，架构的演进是受控的、经过深思熟虑的，而不是AI的随机黑盒。**

2.  **设计规范封装为“设计DNA”**：
    *   你们不是有自己成体系的UI设计规范吗？把它的原则（间距、色板、字体、组件样式、交互模式）封装成一个**可执行的“设计DNA文件”**。
    *   AI在生成任何UI时，必须加载这个文件。它就像一个无法摘掉的滤镜，确保AI生成的所有页面、大屏、APP，都长着同一张脸，遵循同一套交互逻辑。**这不是简单的换肤，而是基因层面的统一。**
    *   更进一步，你可以定义“业务场景设计模式”，比如“工业物联网大屏模式”、“移动巡检模式”。AI识别到相关需求，就直接套用这个顶层设计框架。

3.  **自动化架构与代码合规性门禁**：
    *   在CI/CD流水线中，除了常规的单元测试、集成测试，我们增加一个强大的**“AI架构评审官”**角色。
    *   它会自动扫描AI生成的代码和配置，检查是否偏离了EAB定义的架构原则（如服务间不能有直接数据库依赖）、是否引入了不在白名单内的第三方库、代码风格是否符合规范。任何不合规项，直接阻断流水线，并给出详细的违规报告和改进建议。
    *   **这套机制，保证AI始终在你画好的、并且不断由你拓宽的赛道上狂奔。**

### 问题二：如何构建应对AI“降智”的“逃生舱”？

把命运完全交给AI，是极其危险的。我们必须建立一个**AI降智或离线时，业务不中断、项目可继续的“逃生舱”机制。** 这个逃生舱的核心，就是**将AI的“生成能力”，解耦为一个可降级的服务，同时确保核心资产的独立可操作性。**

**“逃生舱”的设计：**

1.  **业务知识图谱是核心，且完全独立**：
    *   我们之前讨论的那个不断生长的行业知识图谱，绝对不能存放在任何AI大模型的私有格式里。它必须存储在你自己的数据库中，使用开放标准（如属性图模型）。
    *   这意味着，这个图谱可以被任何程序访问、查询、修改，不需要通过AI。它就是你的平台独立积累的、可移植的核心资产。

2.  **开发“无AI模式”的业务建模工作台**：
    *   你的平台必须具备一个**完全的离线/降级模式**。当AI API调用失败或响应质量过低时，用户界面会无缝切换到 **“专家模式”**。
    *   在这个模式下，所有AI对话驱动的步骤，都退化为**可视化、手动的操作**。
        *   **AI需求分析** -> 退化为可视化编辑的**用户故事地图和领域模型画板**。
        *   **AI架构设计** -> 退化为**从EAB快照中进行可视化托拉拽的架构图设计器**。
        *   **AI生成业务规则** -> 退化为我们熟悉的**决策表、决策树可视化编辑器**（这部分的开发绝不能省）。
    *   **关键点**：在“专家模式”下，人类专家产出的不是代码，而是与AI生成物**同构的领域模型、架构模型和规则模型**。这些模型，和AI生成的一样，可以被平台编译器转化为最终代码。

3.  **同构的编译与运行底座**：
    *   无论是AI根据会话生成的模型，还是人类在“逃生舱”里手动搭建的模型，它们都基于同一套元模型（Meta-model）。
    *   因此，它们被送入的是**同一个确定性编译器**，生成同一套微服务框架下的代码。**平台的核心生产力——那个强大的代码生成和部署引擎——绝不依赖AI，它只依赖你们定义的稳定模型。**
    *   **这意味着，没有AI，你们只是失去了“智能顾问”，但绝没有失去“生产工具”。你们依然能比传统开发快5-10倍地交付高质量项目。**

#### 护城河一：领域知识自动进化引擎（Domain Knowledge Evolution Engine, DKEE）

*   **它是如何工作的？**
    1.  **观察**：当你在“专家模式”下，手动为一个“化工行业”的客户，配置了一套异常复杂的“多级审批与安全作业票”规则时，引擎会默默观察你的所有操作。
    2.  **抽象**：引擎利用轻量级机器学习（如序列模式挖掘、聚类分析），分析这次手动配置的结构，并与知识图谱中已有的模式进行对比。
    3.  **提案与进化**：完成后，引擎会主动提示：“D爷，我观察到你在化工行业项目中，定义了一套新的‘作业票-隔离-审批’模式，它不同于我们已有的通用审批流。我可以将它提炼为一个新的‘化工安全作业票领域模式’，并建议将其纳入EAB吗？”
    4.  **验证与固化**：一旦你确认，这个新模式就会被抽象、测试、版本化，永久地加入到知识图谱和EAB中。下次，任何AI或人类顾问在处理类似化工需求时，**都可以直接复用这个进化的、经过实战检验的最佳实践**。
*   **为什么这是壁垒？** 后来者可以抄你的界面，抄你的代码生成器，但他抄不走你**平台上沉淀下来的、覆盖N个行业的、由无数专家经验喂养出来的领域知识图谱**。这个引擎，让你的平台成为一台“行业智慧印钞机”，越用越值钱，越用越准。这正是深度学习思想的巧妙应用，不是去重新发明AlphaGo，而是让它成为你业务模型的“教练”。

#### 护城河二：深度生成式测试与自修复引擎（Deep Generative Testing & Self-Healing Engine）

**这个绝活，直击企业级客户最底层的恐惧：AI生成的系统，你敢用在核心生产环境吗？**

*   **核心绝活**：**利用生成式AI自身，生成海量的、对抗性的、符合行业特征的测试用例，对生成的系统进行“狂轰滥炸”，并实现一定程度的自动修复。**
*   **它是如何工作的？**
    1.  **测试用例生成**：系统交付前，平台会启动这个引擎。它会读取需求文档和领域模型，然后说：“我要测试这个MES排程模块。我会生成10000个测试场景，包括：‘在未来72小时内，随机插入500个不同优先级的VIP订单’、‘模拟3号精密磨床在第4小时发生故障’、‘模拟一个订单的交货期被客户突然从周五提前到周二’。”
    2.  **深度业务逻辑测试**：它不是简单的API测试，而是深入到业务逻辑。它会断言：“在测试场景X后，甘特图上VIP订单的完成时间，必须早于任何同期的普通订单”、“设备故障后，所有受影响工序的状态必须自动变为‘等待重排’。”
    3.  **自动分析与修复提案**：当测试失败，引擎不会只丢给你一个日志。它会分析失败原因，对比领域知识图谱，然后给出提案：“D爷，在1000次插单测试中，有3次高优先级订单没有获得优先。我分析了日志，发现是‘抢占式调度’算法在边界条件下存在瑕疵。我已经为你生成了修复补丁，并回归测试通过，请你审核。”
*   **为什么这是壁垒？** 这背后需要**深厚的AI能力来生成有意义的、非随机的业务测试用例，需要领域知识图谱来验证正确性，需要编译器级别的洞察力来定位和修复Bug**。这远远超出了传统测试工具的范畴。它为你的平台赢得了最宝贵的资产——**企业客户的终极信任**。客户会说：“用你们的平台生成系统，不仅是快，而且是我见过最坚固的。”

### 文件 3：表达式分类器

创建 `src/core/ir/expression-classifier.ts`：

```typescript
/**
 * 表达式分类器
 * 
 * 输入：嵌入在 JSON 中的箭头函数字符串
 * 输出：分级结果（empty / simple / medium / complex）
 */

export interface ClassificationResult {
  level: 'empty' | 'simple' | 'medium' | 'complex';
  params: string[];
  body: string;
  isAsync: boolean;
}

/**
 * 对函数字符串进行分级分类
 */
export function classifyExpression(code: string): ClassificationResult {
  const trimmed = code.trim();

  // 提取参数
  const paramMatch = trimmed.match(/^\(?\s*\{([^}]*)\}\s*\)?\s*=>/);
  const params = paramMatch
    ? paramMatch[1].split(',').map(p => p.trim()).filter(Boolean)
    : [];

  // 提取函数体
  const bodyMatch = trimmed.match(/=>\s*\{([\s\S]*)\}$/);
  const body = bodyMatch ? bodyMatch[1].trim() : '';

  // 判断空函数
  const isEmpty = !body || body === '' || /^\s*$/.test(body);

  if (isEmpty) {
    return { level: 'empty', params, body, isAsync: false };
  }

  // 判断异步
  const isAsync = /async\s/.test(trimmed) || /Promise|new Promise|resolve|reject/.test(body);

  // 判断复杂（循环、嵌套 Promise + 条件）
  if (/for\s*\(|\.forEach\(|\.map\(|\.filter\(|while\s*\(/.test(body)) {
    return { level: 'complex', params, body, isAsync };
  }
  if (/Promise/.test(body) && /if\s*\(/.test(body)) {
    return { level: 'complex', params, body, isAsync };
  }
  if (/eval\s*\(|new Function/.test(body)) {
    return { level: 'complex', params, body, isAsync };
  }

  // 判断中等（Promise、条件判断、API 调用）
  if (/Promise|new Promise|resolve|reject/.test(body)) {
    return { level: 'medium', params, body, isAsync };
  }
  if (/if\s*\(|if\s*\{/.test(body)) {
    return { level: 'medium', params, body, isAsync };
  }
  if (/await\s/.test(body)) {
    return { level: 'medium', params, body, isAsync };
  }
  if (/\.get\(|\.post\(|\.put\(|\.delete\(|fetch\s*\(/.test(body)) {
    return { level: 'medium', params, body, isAsync };
  }

  // 默认：简单
  return { level: 'simple', params, body, isAsync };
}
```

### 文件 4：IR 验证器

创建 `src/core/ir/validator.ts`：

```typescript
/**
 * IR 验证器
 * 
 * 职责：验证 IR 的结构完整性（必填字段、引用完整性）
 * 不做：语义正确性验证（由编译器负责）
 * 
 * 设计理由：
 *   验证器是"轻量级守门员"，只拦截明显的结构性错误。
 *   语义正确性由编译器 + TypeScript 类型系统 + 运行时共同保证。
 *   验证器应在每次清洗后立即调用（< 1ms），不引入重型校验库。
 */

import type { FormPageIR, FieldIR, ExpressionIR } from './types';

export interface ValidationIssue {
  level: 'error' | 'warn';
  path: string;
  message: string;
}

/**
 * 验证 IR 的结构完整性
 */
export function validateIR(ir: FormPageIR): ValidationIssue[] {
  const issues: ValidationIssue[] = [];

  // 1. 必填字段
  if (!ir.id) issues.push({ level: 'error', path: 'id', message: '缺少 id' });
  if (!ir.name) issues.push({ level: 'warn', path: 'name', message: '缺少 name' });
  if (!ir.fields?.length) {
    issues.push({ level: 'error', path: 'fields', message: '字段列表为空' });
  }

  // 2. 字段完整性
  for (let i = 0; i < (ir.fields?.length ?? 0); i++) {
    const field = ir.fields[i];
    const prefix = `fields[${i}]`;

    if (!field.model) {
      issues.push({ level: 'error', path: `${prefix}.model`, message: '缺少 model' });
    }
    if (!field.label) {
      issues.push({ level: 'warn', path: `${prefix}.label`, message: '缺少 label' });
    }
    if (!field.component?.jnpfKey) {
      issues.push({ level: 'error', path: `${prefix}.component.jnpfKey`, message: '缺少组件类型' });
    }
    if (!field.component?.pc) {
      issues.push({ level: 'warn', path: `${prefix}.component.pc`, message: '缺少 PC 端组件映射' });
    }
    if (!field.component?.app) {
      issues.push({ level: 'warn', path: `${prefix}.component.app`, message: '缺少 App 端组件映射' });
    }
  }

  // 3. 表达式引用完整性
  const exprIds = new Set(ir.expressions?.map(e => e.id) ?? []);
  for (let i = 0; i < (ir.fields?.length ?? 0); i++) {
    const field = ir.fields[i];
    if (!field.events) continue;
    for (const [event, exprId] of Object.entries(field.events)) {
      if (exprId && !exprIds.has(exprId)) {
        issues.push({
          level: 'error',
          path: `fields[${i}].events.${event}`,
          message: `引用了不存在的表达式: ${exprId}`,
        });
      }
    }
  }

  // 4. 表达式级别统计
  const complexCount = ir.expressions?.filter(e => e.level === 'complex').length ?? 0;
  if (complexCount > 0) {
    issues.push({
      level: 'warn',
      path: 'expressions',
      message: `有 ${complexCount} 个复杂表达式需人工迁移`,
    });
  }

  return issues;
}

/**
 * 快捷方法：验证是否有 error 级别的问题
 */
export function hasErrors(issues: ValidationIssue[]): boolean {
  return issues.some(i => i.level === 'error');
}
```

```typescript
/**
 * Schema 清洗器
 * 
 * 输入：JNPF 平台返回的原始 JSON（双层嵌套，含函数字符串）
 * 输出：干净的 FormPageIR（纯数据 + 命名表达式）
 * 
 * 清洗管线：
 *   Step 1: unwrapDoubleJson    — 解包双层 JSON
 *   Step 2: extractFormConfig   — 提取表单配置
 *   Step 3: extractFields       — 提取字段列表（扁平化 __config__）
 *   Step 4: extractExpressions  — 提取函数字符串为命名表达式
 *   Step 5: extractDatabaseFields — 提取数据库字段
 *   Step 6: extractListConfig   — 提取列表配置
 *   Step 7: extractMobileConfig — 提取移动端配置
 *   Step 8: extractWorkflow     — 提取工作流绑定
 *   Step 9: validateIR          — 验证 IR 结构完整性
 */

import type {
  FormPageIR, FieldIR, ExpressionIR, FormConfig,
  FieldConfig, ValidationRuleIR, OptionItemIR,
  DatabaseFieldIR, ListConfigIR, ColumnIR, SearchFieldIR,
  MobileConfigIR, WorkflowIR,
} from './types';

// ============================================================
// 入口函数
// ============================================================

export function cleanSchema(rawJson: unknown): FormPageIR {
  // Step 1: 解包双层 JSON
  const data = unwrapDoubleJson(rawJson);

  // Step 2: 提取表单配置
  const config = extractFormConfig(data);

  // Step 3+4: 提取字段 + 表达式
  const { fields, expressions: fieldExprs } = extractFields(data.fields || data.list || []);

  // Step 4b: 提取表单级生命周期表达式
  const lifecycleExprs = extractLifecycleExpressions(data.funcs);
  const expressions = [...lifecycleExprs, ...fieldExprs];

  // Step 5: 提取数据库字段
  const databaseFields = extractDatabaseFields(data.virtualFieldList || []);

  // Step 6: 提取列表配置
  const listConfig = extractListConfig(data.columnData);

  // Step 7: 提取移动端配置
  const mobileConfig = extractMobileConfig(data.appColumnData, data.appFormData);

  // Step 8: 提取工作流
  const workflow = extractWorkflow(data.flowData);

  const ir: FormPageIR = {
    type: 'form',
    id: String(data.id || data.enCode || generateId()),
    name: String(data.fullName || data.enCode || data.name || 'unnamed'),
    config,
    fields,
    databaseFields,
    expressions,
    listConfig,
    mobileConfig,
    workflow,
  };

  // Step 9: 验证
  const issues = validateIR(ir);
  const errors = issues.filter(i => i.level === 'error');
  if (errors.length > 0) {

  }

  return ir;

// ============================================================
// Step 1: 解包双层 JSON
// ============================================================

function unwrapDoubleJson(raw: unknown): Record<string, unknown> {
  if (typeof raw === 'string') {
    try { raw = JSON.parse(raw); } catch { /* 原样返回 */ }
  }

  const obj = raw as Record<string, unknown>;
  const data = obj.data || obj;
  const result: Record<string, unknown> = {};

  for (const [key, value] of Object.entries(data as Record<string, unknown>)) {
    if (typeof value === 'string' && (value.startsWith('{') || value.startsWith('['))) {
      try {
        result[key] = JSON.parse(value);
      } catch {
        result[key] = value;
      }
    } else {
      result[key] = value;
    }
  }

  return result;
}

// ============================================================
// Step 3+4: 提取字段 + 表达式
// ============================================================

function extractFields(fields: unknown[]): { fields: FieldIR[]; expressions: ExpressionIR[] } {
  const fieldIRs: FieldIR[] = [];
  const expressions: ExpressionIR[] = [];

  for (const field of fields) {
    if (!field || typeof field !== 'object') continue;
    const f = field as Record<string, unknown>;
    const config = (f.__config__ || {}) as Record<string, unknown>;
    const model = String(f.__vModel__ || config.fieldName || '');
    const label = String(config.label || f.label || '');
    const jnpfKey = String(config.jnpfKey || config.tag || 'JnpfInput');

    // 组件映射
    const mapping = resolveComponentMapping(jnpfKey);

    // 字段配置
    const fieldConfig: FieldConfig = {
      required: Boolean(config.required),
      defaultValue: config.defaultValue ?? f.defaultValue ?? undefined,
      placeholder: String(f.placeholder || ''),
      disabled: Boolean(f.disabled),
      readonly: Boolean(f.readonly),
      hidden: Boolean(config.hidden),
      span: Number(config.span) || 24,
      labelWidth: config.labelWidth != null ? Number(config.labelWidth) : null,
      maxlength: f.maxlength != null ? Number(f.maxlength) : null,
      showWordLimit: Boolean(f.showWordLimit),
      clearable: f.clearable !== false,
      min: f.min != null ? Number(f.min) : null,
      max: f.max != null ? Number(f.max) : null,
      precision: f.precision != null ? Number(f.precision) : null,
      step: f.step != null ? Number(f.step) : null,
      multiple: Boolean(f.multiple),
      options: extractOptions(f.options || config.options || []),
      dictType: (config.dictionaryType as string) || (f.dictType as string) || null,
      relationData: (f.relationData as FieldConfig['relationData']) || null,
      style: (f.style as Record<string, string>) || {},
    };

    // 校验规则
    const validation = extractValidation(config.regList || []);

    // 事件 → 命名表达式
    const events: FieldIR['events'] = {};
    const on = (f.on || {}) as Record<string, unknown>;
    for (const [eventName, handler] of Object.entries(on)) {
      if (typeof handler === 'string' && (handler.includes('=>') || handler.includes('function'))) {
        const exprId = `field_${model}_on_${eventName}`;
        const classified = classifyExpression(handler);
        expressions.push({
          id: exprId,
          name: `${model}.${eventName}`,
          type: 'field-event',
          ...classified,
          originalCode: handler,
        });
        events[eventName as keyof FieldIR['events']] = exprId;
      }
    }

    fieldIRs.push({
      id: String(config.renderKey || f.id || model || `field_${fieldIRs.length}`),
      model,
      label,
      component: { jnpfKey, pc: mapping.pc, app: mapping.app },
      config: fieldConfig,
      validation,
      events,
    });
  }

  return { fields: fieldIRs, expressions };
}

// ============================================================
// Step 4b: 提取表单级生命周期表达式
// ============================================================

function extractLifecycleExpressions(funcs: unknown): ExpressionIR[] {
  if (!funcs || typeof funcs !== 'object') return [];

  const expressions: ExpressionIR[] = [];
  const funcsObj = funcs as Record<string, unknown>;

  const lifecycleMap: Record<string, ExpressionIR['type']> = {
    onLoad: 'form-lifecycle',
    beforeSubmit: 'form-lifecycle',
    afterSubmit: 'form-lifecycle',
  };

  for (const [name, type] of Object.entries(lifecycleMap)) {
    const code = funcsObj[name];
    if (typeof code !== 'string' || !code.includes('=>')) continue;

    const classified = classifyExpression(code);
    expressions.push({
      id: `form_${name}`,
      name: `form.${name}`,
      type,
      ...classified,
      originalCode: code,
    });
  }

  return expressions;
}

// ============================================================
// 辅助函数
// ============================================================

function extractOptions(options: unknown[]): OptionItemIR[] {
  if (!Array.isArray(options)) return [];
  return options
    .filter(o => o && typeof o === 'object')
    .map(o => ({
      label: String((o as Record<string, unknown>).label || ''),
      value: (o as Record<string, unknown>).value,
      disabled: Boolean((o as Record<string, unknown>).disabled),
    }));
}

function extractValidation(regList: unknown[]): ValidationRuleIR[] {
  if (!Array.isArray(regList)) return [];
  return regList
    .filter(r => r && typeof r === 'object')
    .map(r => ({
      type: ((r as Record<string, unknown>).type as ValidationRuleIR['type']) || 'pattern',
      message: String((r as Record<string, unknown>).message || ''),
      pattern: (r as Record<string, unknown>).pattern as string | undefined,
      min: (r as Record<string, unknown>).min as number | undefined,
      max: (r as Record<string, unknown>).max as number | undefined,
      trigger: ((r as Record<string, unknown>).trigger as 'blur' | 'change') || 'blur',
    }));

function extractDatabaseFields(fields: unknown[]): DatabaseFieldIR[] {
  if (!Array.isArray(fields)) return [];
  return fields
    .filter(f => f && typeof f === 'object')

      id: String((f as Record<string, unknown>).id || `db_${i}`),
      name: String((f as Record<string, unknown>).field || (f as Record<string, unknown>).name || ''),
      type: String((f as Record<string, unknown>).type || 'varchar'),

      nullable: (f as Record<string, unknown>).nullable !== false,
      defaultValue: (f as Record<string, unknown>).defaultValue,
      description: String((f as Record<string, unknown>).description || ''),
    }));
}

function extractListConfig(columnData: unknown): ListConfigIR | undefined {

  const cd = columnData as Record<string, unknown>;
```
