## 二、阻塞项（必须修复）

### 阻塞项1：M5发布候选缺少硬门禁 [P0]

**问题**："Gate + 集成 + Demo"三个概念词，不是可执行标准。§12.3有18个阶段五门禁，§12.4有12个阶段六门禁，M5作为最终里程碑却一个都没有。

**修复**：新增§12.4.1，定义8项M5硬门禁：
- M5-G01 单元测试覆盖率≥80%
- M5-G02 集成测试10场景全绿
- M5-G03 黄金集评分达标（需求准确率≥80%、可编译率≥90%、数据库合规=100%）
- M5-G04 性能指标达标（§10.1.1全部指标）
- M5-G05 安全门禁（10条越权用例全绿 + FounderGuard矩阵通过）
- M5-G06 沙箱稳定性（5并发×30次循环无OOM，P95≤30s）
- M5-G07 文档完整性（12章完成 + 部署手册交付）
- M5-G08 Demo验收（业务专家30分钟端到端生成应用，具有一票否决权）

### 阻塞项2：里程碑间依赖关系未明确 [P0]

**问题**：§12.1表格无"前置条件"列，无法判断M2是否依赖M1。

**修复**：修订§12.1表格，增加"前置条件"列和依赖图：
```
M0 → M0.5 → M1 → M2 → M3 → M4 → M5(RC1)
              ↑                ↑
熔炉: FM0→FM1→FM2→FM3(W15)─────┘
```
关键路径18周，熔炉FM3与M4联调通过方可进入M5。

### 阻塞项3：与第十章/第十一章交叉引用完全断裂 [P0]

**问题**：§12.1里程碑描述孤立，未引用§10.1性能指标、§10.3.3 OpenTelemetry、§11.3黄金集等验收标准。

**修复**：在每个里程碑后增加"验收标准引用"小节，明确引用具体章节和表格。

## 三、重大缺陷（强烈建议修复）

### 缺陷4：全平台统一验收时间轴模糊 [P1]

**修复**：§12.5增加2026年日历时间轴（W1-W18），标注当前进度（W7，M2开发中）、关键路径剩余11周、风险点（FM3-M4联调窗口仅1周，建议提前到W14准备）。

### 缺陷5：熔炉-工作室联调验收标准完全缺失 [P1]

**修复**：新增§12.5.1，定义7项联调用例（L1-L7）：
- L1 原料包导出（IrCorpus.zip，AES-256加密）
- L2 原料包传输到熔炉（HTTP 200 + 日志确认）
- L3 熔炉自博弈生成补丁（KnowledgePatch_v1.zip）
- L4 补丁签发（创始人TOTP验证 + 私钥签名）
- L5 补丁注入工作室（BASE_KNOWLEDGE_NODE UPSERT成功）
- L6 Agent消费新知识（RAG召回率>0）
- L7 端到端验证（黄金集评分比之前轮次高≥5%）

### 缺陷6：§12.6与运行态对照表流于形式 [P1]

**修复**：修订对照表，增加"差异说明"列。发现3项重大差异（OpenTelemetry/黄金集/M5硬门禁在运行态缺失），4项轻微差异（zxdev模块/MCP接口/纸面方案表/待建页面）。

## 四、一般缺陷（建议修复）

### 缺陷7：状态标记语义混乱 [P2]

**修复**：全文档统一7种状态标记：
- ✅ COMPLETED（代码交付+测试通过+文档更新）
- 🔄 IN_PROGRESS（开发中/测试中）
- ❌ NOT_STARTED（未开始）
- 🔷 DEFERRED（排除到V2）
- ⬜ PENDING（依赖外部条件）
- ⚠️ AT_RISK（存在风险）
- ❌ BLOCKED（被阻塞）

### 缺陷8：风险与缓解缺少量化指标 [P2]

**修复**：§12.7增加"量化验收标准"和"验证方式"列，每项风险对应可测量验收条件（如"5并发×30次循环，内存峰值<14G"）。

### 缺陷9：缺少里程碑甘特图 [P2]

**修复**：§12.1引用§4.8已有甘特图，或新增可视化时间轴。
