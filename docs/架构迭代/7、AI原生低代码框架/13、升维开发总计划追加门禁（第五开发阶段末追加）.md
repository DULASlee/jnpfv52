**具体交付：**

```

jnpf-web-vue3/src/core/ai/pipeline/stages.ts           — 5个阶段定义
jnpf-web-vue3/src/core/ai/pipeline/state-machine.ts    — 流水线状态机
jnpf-web-vue3/src/core/ai/__tests__/pipeline.test.ts   — 流水线测试
```

**核心逻辑：**

```typescript
// 5个阶段定义
type PipelineStage = 'requirement' | 'architecture' | 'design' | 'development' | 'delivery'

// 流水线状态
interface PipelineState {
  stage: PipelineStage
  requirement?: RequirementAnalysis
  architecture?: ArchitectureDesign
  design?: { ui: UIDesign; database: DatabaseDesign }
  development?: { project: GeneratedProject; target: CompileTarget }
  delivery?: { url: string; zip: Blob }
}

// OrchestratorAgent 串联4个智能体
class OrchestratorAgent {
  async advance(state: PipelineState, userInput: string): Promise<PipelineState>
  // 每次advance推进一个阶段
  // 人类在每个阶段输出后确认才进入下一阶段
  // AI降智时自动切换专家模式
}
```
