### B-02 + I-13：stale 全阶段覆盖 + stale 触发数据流（合并项）
| 维度                     | 决策                                                         |
| ------------------------ | ------------------------------------------------------------ |
| **怎么改**               | 1. **全阶段超时定义**：stage1/2（7天）、stage3（3天）、stage4（7天）、stage5（14天）<br>2. **双向恢复**：`stale → stageN`（回到原阶段，非强制回 stage1）<br>3. **兜底终止**：stale 超 30 天 → 自动 `abandoned`<br>4. **新增 `StaleMonitorService`**（Hangfire 定时任务，每小时扫 `BASE_AI_PIPELINE`）<br>5. **新增字段**：`F_STALE_FROM_STAGE`（记录原阶段，resume 时自动回填） |
| **谁来改**               | 首席架构师（流程图 + DDL）+ 后端工程师（StaleMonitorService + 接口） |
| **什么时候改**           | **文档今天定**，代码本周完成                                 |
| **接口契约**             | 见下方 2 个端点                                              |
| **必须今天锁定的接口**： |                                                              |
```yaml
# 1. 管理员查看 stale 流水线
端点: GET /api/pipeline/stale
权限: 租户管理员
响应:
  {
    "code": 200,
    "data": {
      "list": [
        {
          "pipelineId": "...",
          "staleFromStage": "stage2",
          "staleAt": "2026-06-10T...",
          "createdBy": "user_001"
        }
      ]
    }
  }
# 2. 恢复 stale 流水线
端点: POST /api/pipeline/{id}/resume
权限: 创建者 或 租户管理员
请求体:
  {
    "targetStage": "stage2"   # 可选，默认从 F_STALE_FROM_STAGE 自动取
  }
响应:
  {
    "code": 200,
    "data": {
      "currentStage": "stage2",
      "status": "running",
      "resumedAt": "2026-06-20T..."
    }
  }
```

### I-02：stage2→stage3 开发者否决闭环
| 维度           | 决策                                                         |
| -------------- | ------------------------------------------------------------ |
| **怎么改**     | 定义"否决→修改→重审"闭环：<br>1. 开发者否决**必须填原因**，系统通知业务专家<br>2. 最多 **3 轮**，第 3 轮自动升级管理员仲裁<br>3. 状态流转：`stage2 → stage2`（自环，非回退）<br>**DDL 补充**：`BASE_AI_PIPELINE_MESSAGE` 加 `F_REVIEW_DECISION`、`F_REVIEW_REASON`、`F_REVIEW_ROUND`；`BASE_AI_PIPELINE` 加 `F_REJECT_COUNT` |

| **什么时候改** | 阶段五并行                                                   |
| **接口契约**   | 复用 B-01 通用确认接口：`decision: "reject"` + `reason` 必填 |
