### 决策项1：B-03 全量替换 vs 增量修改（双模式）

**核心问题**：文档§4.7.2决定“全量替换IR”，但用户期望“增量修改”是局部修改。

**可选方案**：

| 方案      | 描述                                                         | 优点                   | 缺点                               | 建议       |
| --------- | ------------------------------------------------------------ | ---------------------- | ---------------------------------- | ---------- |
| **方案A** | **双模式并存**：用户可选“全量回退”或“分治编辑”，分治编辑判定阈值为“受影响节点数 < 30% 且 < 50 个” | 满足所有场景，语义清晰 | 实现复杂度高                       | ✅ **推荐** |
| **方案B** | **仅全量模式**：用户只能回退到阶段N，全量替换IR              | 实现简单，降低复杂度   | 不符合用户期望，小改动也要全量重跑 | ❌ 不推荐   |
| **方案C** | **仅分治模式**：用户只修改指定节点，不允许全量回退           | 真正“增量修改”         | 无法处理架构级变更                 | ❌ 不推荐   |

**需拍板**：选择 **方案A / B / C**，以及分治编辑的判定阈值（如选定方案A）。
