### 二、完整 DDL 补丁（核心 4 张表）

#### 1. `BASE_IR_VERSION`（I-09 + I-10 + B-03 合并）

```sql
-- 在 v2.0 §4.7.5 已有的表结构上追加：
ALTER TABLE BASE_IR_VERSION ADD
  F_REPLACE_MODE       NVARCHAR(20) DEFAULT 'full',   -- 'full' | 'partial'
  F_AFFECTED_NODE_COUNT INT DEFAULT 0,               -- 受影响节点数（partial 模式有效）
  F_AFFECTED_SCOPE     NVARCHAR(MAX) NULL,           -- JSON: 受影响范围标签
  F_TRIGGERED_BY       NVARCHAR(50) NULL,             -- user_id 或 'auto'
  F_CHANGE_SUMMARY     NVARCHAR(500) NULL,            -- 改动摘要（用户输入或自动生成）
  F_PARENT_VERSION     INT NULL,                      -- 父版本号（用于追溯）
  F_SUPERSEDED_BY      BIGINT NULL,                   -- 被哪个版本取代（自引用）
  F_DELETED_AT         DATETIME NULL,                 -- 软删除时间（永远不物理删）
  CONSTRAINT FK_IR_VERSION_PARENT FOREIGN KEY (F_PARENT_VERSION) 
    REFERENCES BASE_IR_VERSION(F_VERSION);
```

**乐观锁机制**：所有 UPDATE 必须 `WHERE F_ID = ? AND F_VERSION = ?`，更新后 `F_VERSION = F_VERSION + 1`。清理服务删除前再次校验 `F_VERSION`，防止并发覆盖。

#### 2. `BASE_AI_PIPELINE`（I-12 + I-13 合并）

```sql
ALTER TABLE BASE_AI_PIPELINE ADD
  -- blocked 相关（I-12）

  F_BLOCKED_AT       DATETIME NULL,

  -- stale 相关（I-13）

  -- 通用
  F_STATUS           NVARCHAR(20) DEFAULT 'active',  -- 'active'|'stale'|'blocked'|'abandoned'|'completed'
  F_ABANDONED_AT     DATETIME NULL,
  F_ABANDONED_BY     NVARCHAR(50) NULL,
  F_ABANDON_REASON   NVARCHAR(500) NULL;

CREATE INDEX IDX_PIPELINE_STATUS ON BASE_AI_PIPELINE(F_STATUS, F_MODIFY_TIME);
CREATE INDEX IDX_PIPELINE_BLOCKED ON BASE_AI_PIPELINE(F_BLOCKED_AT) WHERE F_BLOCKED_AT IS NOT NULL;
CREATE INDEX IDX_PIPELINE_STALE ON BASE_AI_PIPELINE(F_STALE_AT) WHERE F_STALE_AT IS NOT NULL;
```
