**⑤ 应用分治编辑**
```yaml
端点: POST /api/pipeline/{id}/surgical-edit
权限: 创建者 或 租户管理员
鉴权: JWT + 角色权限
请求体:
  {
    "patches": [
      {
        "nodeId": "comp_023",
        "operation": "replace",
        "path": "$.pages[0].components[2].props.label",
        "value": "请假天数（含半天）",
        "reason": "需求变更：支持半天请假"
      },
      {
        "nodeId": "tbl_005_col_003",
        "operation": "replace",
        "path": "$.tables[4].columns[2].dataType",
        "value": "DECIMAL(4,1)",
        "reason": "支持半天，需小数精度"
      }
    ],
    "baseIrVersion": 3                    # 基于哪个 IR 版本编辑
  }
响应:
  {
    "code": 200,
    "data": {
      "patchId": "...",
      "newIrVersion": 4,
      "validationResult": {
        "cleanSchema": true,
        "validateIR": true,
        "vue-tsc": { "passed": true, "errors": [] }
      },
      "status": "applied",
      "appliedAt": "2026-06-20T..."
    }
  }
业务规则:
  - 每个 patch 必须经过 Agent 视图边界校验（B-03-C1）
  - 全部 patches 应用后执行完整校验链
  - 校验失败 → 所有 patches 回滚（F_STATUS = 'failed'），IR 不变
  - 校验成功 → 自动创建新 IR 版本快照
错误码:
  - 400: patch 格式错误 / baseIrVersion 不存在
  - 403: patch 越权修改（修改了非 ownedNodeTypes 范围的节点）
  - 409: 校验链失败（返回详细错误）
```

  - 回滚后仍需执行校验链
