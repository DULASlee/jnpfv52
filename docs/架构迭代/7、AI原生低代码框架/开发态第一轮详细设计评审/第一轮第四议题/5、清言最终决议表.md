## 四、B-06 SSE事件Schema：18种事件类型（取并集，统一术语）
玛维思的13种与清言的12种取并集，**统一使用"stage"（淘汰"phase"）**，使用下划线命名：
```typescript
export type PipelineSSEEventType =
  // ── 流水线级（6种）──
  | 'pipeline_created' | 'pipeline_cancelled' | 'pipeline_completed'
  | 'pipeline_blocked' | 'pipeline_stale' | 'pipeline_abandoned'
  // ── 阶段级（4种）──
  | 'stage_started' | 'stage_completed' | 'stage_failed' | 'confirmation_required'
  // ── Agent级（4种）──
  | 'agent_thinking' | 'agent_output' | 'agent_warning' | 'agent_checkpoint'
  // ── 系统级（4种）──
  | 'timeout_alert' | 'retrying' | 'validation_result' | 'ping';
export interface PipelineSSEEvent {
  type: PipelineSSEEventType;
  eventId: string;              // 唯一ID，断线重连锚点（玛维思补）
  timestamp: string;
  pipelineId: string;
  tenantId: string;
  stage: string;
  data: Record<string, any>;
}
```
**SSE连接参数**：
- 端点：`GET /api/pipeline/{id}/events?token={jwt}&lastEventId={eventId}`
- 心跳：30秒 `ping`，90秒无响应视为断连
- 重连：指数退避（maxAttempts=5, initialDelay=1s, multiplier=2）
