| 冲突项                                                       | §8.1.1 路由定义            | §8.1.4 映射路由       | 实际应选 |
| ------------------------------------------------------------ | -------------------------- | --------------------- | -------- |
| PipelineManager.vue                                          | `/studio/expert/quick-app` | `/expert/my-projects` | 待裁定   |

- `/studio/expert/my-projects`：查看历史项目列表（可复用 PipelineManager 的列表部分）

### 问题 P-02：IRDesigner.vue 优先级偏高

- 本平台的核心价值主张是 **AI 原生**——业务专家不碰 IR，开发者主要用 AI 顾问
- IRDesigner 是 **AI 失败时的逃生舱**，使用频率低
- §1.2.1 明确："AI 可用时提效 10 倍，AI 不可用时 100% 回退到手工模式"——手工模式是兜底，不是主路径
**建议降级**：IRDesigner.vue 从 P0 → **P1**。与 SandboxMonitor.vue 同级。P0 应聚焦于 AI 驱动的主流程页面（PipelineManager + AiChatPanel）。

**建议补入**：
| 页面                | 路由                    | 优先级 | 核心组件                                       | 后端 API 依赖          |

## 四、UI 草图与布局规格（§8.3）— 🟡 修正级
### 问题 L-01：PipelineManager.vue 三栏布局最小宽度不足
§8.3.1 定义：项目列表(280px) + AI对话(flex:1) + 实时预览(360px) = 最小需 280+360=640px 固定 + 对话区。
在 1366px 屏幕上：1366 - 280 - 360 = 726px 对话区（含侧栏 220px 后实际更少）。
在 1280px 屏幕上：1280 - 220(侧栏) - 280 - 360 = 420px 对话区——**过于狭窄**。
**建议**：
- 将项目列表改为可折叠侧栏（展开 280px / 折叠 64px）
- 或将实时预览改为底部抽屉（可拉起/收起）
- 或设定最小断点：当视口 < 1200px 时，项目列表切换为浮层弹窗
### 问题 L-02：SSE 事件类型与后端不完整对齐
§8.3.2 定义 7 种 SSE 事件，但 §5.XX 定义了更多字段：
| 后端 SSE 字段 (§5.XX)  | §8.3.2 是否覆盖 | 缺失影响                    |
| ---------------------- | :-------------: | --------------------------- |
| stage                  |        ✅        | —                           |
| phase                  |        ✅        | —                           |
| progress               |        ✅        | —                           |
| thought                |        ✅        | —                           |
| agent                  |        ❌        | 无法区分是哪个 Agent 在思考 |
| warning                |        ✅        | —                           |
| timeout_alert          |        ✅        | —                           |
| elapsed_ms             |        ❌        | 无法显示已耗时              |
| estimated_remaining_ms |        ❌        | 无法显示预估剩余时间        |
| **建议补充**：         |                 |                             |
| 事件类型               |    SSE phase    | 颜色                        |
| ----------             |   -----------   | ------                      |
| Agent 切换             |  agent_switch   | 蓝色标签                    |
| 进度更新               |    progress     | 无                          |
| 批次切换               |  batch_switch   | 紫色边框                    |
| 校验阶段               |  validating_*   | 灰色                        |
### 问题 L-03：双视图切换（业务/技术）的 UI 位置未定义
§5.4.2 定义了 `GET /api/pipeline/{id}/artifacts/{stage}?view=business|technical`，§4.1.1 定义了阶段2→3的双视图门禁。但 §8.3 中无任何页面展示"双视图切换"的 UI 设计：
- 切换控件放在哪里？（顶栏 Tab？侧栏切换？下拉选择？）
- 业务语言版和技术语言版是否可并排对比？
- 切换后页面内容如何变化？
**建议补充**：在 PipelineManager.vue 的实时预览区域，增加"视图切换"控件：
```
┌─ 实时预览 ──────────────────────────────┐
│  [业务视图]  [技术视图]  ← a-radio-group │
│                                          │
│  (当前视图内容)                           │
└──────────────────────────────────────────┘
```
阶段 2 门禁时，需两步确认——业务专家先看业务视图，开发者再看技术视图。
### 问题 L-04：IRDiffViewer 组件未描述
§8.3.1 提到 PipelineManager.vue 右侧实时预览包含 `IRDiffViewer`，但：
- 无布局规格

## 五、设计规范补充（§8.4）— ⚪ 建议级
### 建议 S-01：暗色模式预留
当前仅定义亮色主题 Token。考虑到开发者用户群体偏好，建议：
- 在 CSS 变量体系中预留 `[data-theme="dark"]` 作用域
- 本期不实施，但变量命名应避免硬编码颜色值
### 建议 S-02：性能预算可能超标
§8.4.7 设定 JS 体积 < 500KB gzip，但以下依赖可能超标：
- d3-force（GraphExplorer.vue）：~80KB gzip
- vuedraggable（IRDesigner.vue）：~20KB gzip
- mermaid（时序图/流程图渲染，如果需要）：~150KB gzip
- ant-design-vue 全量引入风险
**建议**：强制按需导入 + 路由级代码分割验证（每个路由 < 200KB gzip）。
### 建议 S-03：键盘快捷键缺省 AI 对话场景
§8.4.5 定义了 `Ctrl+Enter` 发送、`Shift+Enter` 换行，但缺少：
- `Ctrl+L`：清空对话
- `Ctrl+Shift+R`：重新生成最后一条 AI 回复
- `Esc`：取消当前 AI 流式输出
