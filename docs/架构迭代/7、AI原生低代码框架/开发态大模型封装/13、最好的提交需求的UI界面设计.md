## 当前页面的问题分析

从你描述的当前页面和参考的 MiMo、Cursor 界面来看，问题非常明确：

### 当前页面的致命问题

```
当前布局：
┌──────────────────────────────────────┐
│  提交需求 ×                           │  ← 页签标题（多余）
├──────────────────────────────────────┤
│  DeepSeek V4 Pro | 阶段1:需求分析 | 新对话 │  ← 工具栏
├──────────────────────────────────────┤
│                                      │
│     （巨大空白）                      │  ← 没有欢迎语、没有引导
│                                      │
├──────────────────────────────────────┤
│  ①需求分析 ②架构设计 ③总体设计       │  ← 五阶段图标，又大又静止
│  ④自动开发 ⑤交付验证                 │    占据中间大量空间
│  当前阶段: 需求分析                   │
│  [查看详情] [确认并推进]              │  ← 按钮放在这里用户根本看不到
├──────────────────────────────────────┤
│                                      │
│  AI 回复被框在固定大小文本框里        │  ← 核心内容反而被挤压
│  看起来费劲                          │
│                                      │
├──────────────────────────────────────┤
│  [+] 有问题尽管问，Enter发送 [发送]   │  ← 输入栏
└──────────────────────────────────────┘

问题总结：
1. 五阶段进度条占据黄金位置，但它只是"状态指示"，不是"交互主体"
2. AI 回复区域被挤压在两个固定区域之间，阅读体验极差
3. 确认按钮放在进度条下面，用户要滚动才能看到
4. 整体还是"表单+列表"的旧思维，不是"对话式"的 AI 交互
```

**MiMo 和 Cursor 的共同点：**

| 设计原则       | MiMo         | Cursor       | 当前系统（反面）   |
| -------------- | ------------ | ------------ | ------------------ |
| 对话区占满中间 | ✅ 全屏滚动   | ✅ 全屏滚动   | ❌ 被进度条挤压     |
| 进度/状态信息  | 顶部一行文字 | 顶部一行 Tab | ❌ 中间一大块       |
| 操作按钮位置   | 对话流内     | 对话流内     | ❌ 对话外面单独区域 |
| AI 回复空间    | 无高度限制   | 无高度限制   | ❌ 固定文本框       |
| 老消息滚动     | 自然上滚     | 自然上滚     | ❌ 被截断           |

## 关键设计变化对比

| 维度              | 当前设计（错误）           | 新设计（对标 MiMo + Cursor）                |
| ----------------- | -------------------------- | ------------------------------------------- |
| **五阶段进度条**  | 中间一大块，占据黄金空间   | 顶栏一行文字 `阶段 1/5: 需求分析`，不抢空间 |
| **AI 回复区域**   | 固定大小文本框，被挤压     | 全宽无限制，对话流自然向下滚动              |
| **确认/推进按钮** | 在进度条下面，要滚动才看到 | 在 AI 对话流末尾，自然跟着内容走            |
| **思考过程**      | 整个页面显示"AI 思考中"    | AI 消息气泡内折叠显示思考过程               |
| **策略选项**      | 无                         | AI 气泡内嵌可点击的卡片按钮                 |
| **文档预览**      | 无                         | AI 气泡内嵌文档卡片 + 下载链接              |
| **阶段完成提示**  | 系统消息（分割线文字）     | AI 气泡内嵌操作卡片（确认/回退）            |
| **整体感觉**      | 表单 + 列表（旧思维）      | 对话流（AI 原生交互）                       |

## 核心设计原则

```
1. 对话流是主体
   - 用户消息和 AI 消息交替排列
   - 中间不插入任何与对话无关的固定 UI 元素
   - 老消息自然上滚，新消息自然追加

2. 所有交互都在对话流内
   - 确认/推进按钮：AI 回复末尾的卡片
   - 策略选择：AI 回复中的可点击卡片
   - 文档下载：AI 回复中的文档卡片
   - 追问输入：复用底部输入框，不需要额外区域

3. 顶栏只放状态信息
   - 模型选择器 + 阶段进度（一行文字）+ 新对话按钮
   - 不放任何操作按钮
   - 高度固定 48px，不抢空间

4. 底部输入栏固定
   - 附件按钮 + 输入框 + 发送按钮
   - 始终可见，不需要滚动到页面底部
   - 输入框提示文字随阶段变化

5. 状态信息内联
   - 当前阶段：顶栏一行文字，不单独占区域
   - 阶段切换：对话流中一条系统消息 "✅ 已进入阶段 2: 架构设计"
   - 进度总览：点击顶栏的「阶段详情」展开浮层（不默认显示）
```

## 给工程师的实现指令

需要改造的文件只有一个：

**`src/views/studio/components/AiChatPanel.vue`**

改造要点：

```
1. 移除中间的 PipelineStageBar（五阶段大图标区域）
2. 顶栏改为一行：模型选择 | 阶段 N/5: 名称 | 详情按钮 | 新对话
3. 消息区占满中间全部空间（flex: 1, overflow-y: auto）
4. AI 消息气泡中嵌入：
   - 思考过程（折叠）
   - 策略选项卡片（可点击）
   - 文档预览 + 下载
   - 确认/回退按钮
5. 底部输入栏固定
6. 阶段详情用浮层/抽屉，默认不显示
```

// 发送消息（SSE 流式）
async function sendMessage(content: string) {
  if (!content.trim()) return;
  loading.value = true;
  autoScroll.value = true;

  // 添加用户消息
  messages.value.push({
    id: Date.now(),
    role: 'user',
    content,
    time: new Date().toLocaleTimeString(),
  });
  scrollToBottom();

  // 创建 Pipeline（如果还没有）
  if (!pipelineId.value || pipelineId.value === 0) {
    try {
      const res = await defHttp.post({
        url: '/api/studio/pipeline/execute/create',
        data: { requirement: content },
      });
      pipelineId.value = res.pipelineId || res.id;
    } catch (e: any) {
      antMessage.error('创建失败: ' + (e?.message || '未知错误'));
      loading.value = false;
      return;
    }
  }

  // 添加 AI 消息占位
  const aiMsgId = Date.now() + 1;
  const aiMsg: any = {
    id: aiMsgId,
    role: 'assistant',
    content: '',
    thinking: '',
    thinkingCollapsed: false,
    strategies: [],
    document: null,
    ir: null,
    stageConfirmable: false,
    stageConfirmed: false,
  };
  messages.value.push(aiMsg);

  try {
    abortController.value = new AbortController();

    // SSE 流式请求
    const sseUrl = buildSSEUrl(`/api/studio/pipeline/execute/${pipelineId.value}/events`);
    const response = await fetch(sseUrl, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        message: content,
        stage: currentStage.value,
        provider: selectedProvider.value,
      }),
      signal: abortController.value.signal,
    });

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    const reader = response.body?.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    if (reader) {
      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop() || '';

        for (const line of lines) {
          if (!line.startsWith('data: ') || line === 'data: [DONE]') continue;

          try {
            const data = JSON.parse(line.substring(6));
            const msg = messages.value.find(m => m.id === aiMsgId);
            if (!msg) continue;

            switch (data.type) {
              case 'thinking':
                msg.thinking += (data.content || '');
                break;
              case 'token':
              case 'delta':
                msg.content += (data.content || data.delta?.content || '');
                if (autoScroll.value) scrollToBottom();
                break;
              case 'strategy':
                msg.strategies = data.strategies || [];
                break;
              case 'document':
                msg.document = data.document;
                break;
              case 'ir':
                msg.ir = data.ir;
                break;
              case 'stage_complete':
                msg.stageConfirmable = true;
                break;
              case 'done':
                break;
              case 'error':
                msg.content += `\n\n⚠️ ${data.content || 'AI 响应异常'}`;
                break;
            }
          } catch { /* 忽略解析错误 */ }
        }
      }
    }
  } catch (e: any) {
    if (e.name === 'AbortError') {
      const msg = messages.value.find(m => m.id === aiMsgId);
      if (msg) msg.content += '\n\n⏹️ [已停止生成]';
    } else {
      const msg = messages.value.find(m => m.id === aiMsgId);
      if (msg && !msg.content) msg.content = `⚠️ ${e.message || '发送失败，请重试'}`;
    }
  } finally {
    loading.value = false;
    abortController.value = null;
    if (autoScroll.value) scrollToBottom();
  }
}

// 确认阶段推进
async function handleConfirmStage(msg: any) {
  try {
    await defHttp.post({
      url: `/api/studio/pipeline/execute/stage/${pipelineId.value}/confirm`,
      data: { stage: currentStage.value, approved: true },
    });

    msg.stageConfirmed = true;

    if (currentStage.value >= 5) {
      emit('pipeline-complete', { stage: 5 });
      antMessage.success('全部阶段已完成！');
      return;
    }

    currentStage.value++;
    updateStageStatus();

    messages.value.push({
      id: Date.now(),
      role: 'system',
      content: `✅ 已进入阶段 ${currentStage.value}: ${stages.value[currentStage.value - 1]?.name}`,
    });
    scrollToBottom();

    // 自动触发下一阶段
    sendMessage(`请开始阶段 ${currentStage.value}：${stages.value[currentStage.value - 1]?.name}`);
  } catch (e: any) {
    antMessage.error('确认失败: ' + (e?.message || ''));
  }
}

// Markdown 渲染
function renderMarkdown(text: string): string {
  if (!text) return '';
  return text
    .replace(/^### (.*$)/gm, '<h3>$1</h3>')
    .replace(/^## (.*$)/gm, '<h2>$1</h2>')
    .replace(/^# (.*$)/gm, '<h1>$1</h1>')
    .replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>')
    .replace(/\*(.*?)\*/g, '<em>$1</em>')
    .replace(/`(.*?)`/g, '<code>$1</code>')
    .replace(/^\s*[-*] (.*$)/gm, '<li>$1</li>')
    .replace(/^\s*(\d+)\. (.*$)/gm, '<li>$2</li>')
    .replace(/\n/g, '<br>');
}

// ====== 滚动控制 ======
function scrollToBottom() {
  nextTick(() => {
    if (chatStreamRef.value) {
      chatStreamRef.value.scrollTop = chatStreamRef.value.scrollHeight;
    }
  });
}

function scrollToTop() {
  chatStreamRef.value?.scrollTo({ top: 0, behavior: 'smooth' });
}

function handleScroll() {
  const el = chatStreamRef.value;
  if (!el) return;

  const scrollTop = el.scrollTop;
  const scrollHeight = el.scrollHeight;
  const clientHeight = el.clientHeight;

  // 距离顶部 > 200px 时显示向上按钮
  showScrollUp.value = scrollTop > 200;
  // 距离底部 > 200px 时显示向下按钮
  showScrollDown.value = scrollHeight - scrollTop - clientHeight > 200;
  // 任一按钮需要显示时，容器显示
  showScrollButtons.value = showScrollUp.value || showScrollDown.value;

  // 距离底部 < 100px 时认为用户在看最新消息，开启自动滚动
  autoScroll.value = scrollHeight - scrollTop - clientHeight < 100;
}
