## 关键设计:发现并修复了 3 个真实 bug

跑 e2e 过程中,Mock 服务暴露了 3 个真实问题,这些**生产环境也会遇到**:

1. **跨事件一致性检查过严**——把所有"报废率"开头的条件都当成同一个,误判。修复:只检查 EXACT 同名条件
2. **错误反馈失效**——Retry 循环里 context 每次重建,导致 `last_errors` 永远从空开始,LLM 错误率不下降。修复:context 跨 retry 保留
3. **Pattern 提炼重复**——温启动时永远提"新"Pattern,但其实应该 update 已有 Pattern 的 frequency。修复:增量更新已有 Pattern

**这正是 e2e 测试的价值**——它不仅验证功能,还发现真实 bug。
