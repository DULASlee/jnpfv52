## 文档核心结论

**架构决策：在现有框架上升级扩展，不另建 IoT 版框架。**

**需求 6（物联网实时通道）**需要新建基础设施，但同样是旁路扩展：
- MQTT：推荐 EMQX 外部 Broker + MQTTnet .NET 客户端

- 实时推送：激活已有的 SignalR 框架骨架（仅需 Startup 加 2 行）
- 设备管理：新建 `modularity/iot/` 三件套
