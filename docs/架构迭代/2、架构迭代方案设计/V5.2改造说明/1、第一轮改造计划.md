## 5. Layer 1 详细计划 — 登录 + 菜单

### 5.1 目标与验证标准

**目标**：登录后 API 返回 v5.2 出厂级菜单树；前端路由可匹配（浏览器验证为加分项）。

**验证标准**：

| #    | 检查项     | 通过条件                                                     |
| ---- | ---------- | ------------------------------------------------------------ |
| V1   | 登录       | `POST /api/oauth/Login` → code 200 + Bearer token            |
| V2   | 当前用户   | `GET /api/oauth/CurrentUser?type=Web` + `jnpf-origin: pc` → code 200 |
| V3   | 菜单非空   | `data.menuList.length > 0`，无 D1044                         |
| V4   | 系统列表   | `data.userInfo.systemIds` 含 `mainSystem`                    |
| V5   | admin 身份 | `F_STANDING=1`，`F_IS_ADMINISTRATOR=1`                       |
| V6   | 路由抽样   | 抽 3 条菜单 `urlAddress`，与前端 `views/` 路径可对应         |

### 5.2 架构师清单 → v5.2 表映射修正

| 架构师原表          | v5.2 实际情况         | 处理方式                                                     |
| ------------------- | --------------------- | ------------------------------------------------------------ |
| `BASE_USERROLE`     | **不存在**            | 使用 `BASE_USER.F_ROLE_ID`（逗号分隔角色 ID）                |
| `BASE_USERORGANIZE` | **不存在**            | 使用 `BASE_USER.F_ORGANIZE_ID` + 可选 `BASE_USER_RELATION`（`F_OBJECT_TYPE='Organize'`） |
| `BASE_PERMISSION`   | **不存在**（Layer 2） | v5.2 用 `BASE_MODULE_BUTTON` + `BASE_AUTHORIZE`（`F_ITEM_TYPE='button'`） |

### 5.4 菜单 `BASE_MODULE` 编写策略（核心难点）

**方法：前端路由反推 + 最小菜单集迭代**

```
Step A  导出 v5.2 前端静态路由
        源：d:\JNPF-v52\jnpf-web-vue3\src\router\routes\basic.ts
            d:\JNPF-v52\jnpf-web-vue3\src\views\**\*.vue（glob 匹配）

Step B  建立映射表（单独文件 v52-menu-route-map.csv）
        字段：enCode | fullName | urlAddress | type(1目录2页面) | parentEnCode | systemId

Step C  Phase 1 最小集（约 15–20 条）
        必含：系统管理、权限管理、在线开发 等顶级目录 + 若干叶子页
        目标：左侧出现可点击菜单，页面路由不 404

Step D  Phase 2 扩展集
        按模块逐个补全，每条菜单 INSERT 后 curl 验证 CurrentUser

Step E  BASE_AUTHORIZE 同步
        超级管理员角色 F_OBJECT_ID → 所有 module/system 的 F_ITEM_ID
```

**`BASE_MODULE` 关键字段约定**（来源：`ModuleEntity.cs`）：

| 字段             | Layer 1 填值规则                                         |
| ---------------- | -------------------------------------------------------- |
| `F_ID`           | GUID 或语义 ID（如 `mainSystem` 用于 SYSTEM 表）         |
| `F_TENANT_ID`    | `'0'`（与当前单租户过滤一致）                            |
| `F_PARENT_ID`    | 顶级 `'-1'`                                              |
| `F_TYPE`         | 1=目录，2=页面                                           |
| `F_EN_CODE`      | 与前端权限/路由 key 一致，如 `system`、`permission.user` |
| `F_FULL_NAME`    | 中文菜单名                                               |
| `F_URL_ADDRESS`  | 前端路由 path，如 `/system/sysConfig`                    |
| `F_CATEGORY`     | `'Web'`（CurrentUser 过滤条件）                          |
| `F_SYSTEM_ID`    | `'mainSystem'` 或对应 `BASE_SYSTEM.F_ID`                 |
| `F_ENABLED_MARK` | `1`                                                      |
| `F_DELETE_MARK`  | NULL                                                     |
