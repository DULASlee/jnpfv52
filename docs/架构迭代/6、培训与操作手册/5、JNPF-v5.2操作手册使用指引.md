## 常见场景速查

### 场景 1：「我设计了一个表单，保存了但发布失败」

→ 手册一 **第四章 4.1**（保存 vs 发布区别）  
→ 最可能原因：`formData` 为空（**COM1013**）或 `columnData` 为空（**COM1014**）

### 场景 2：「App 端看不到我发布的菜单」

→ 手册三 **第四章 4.3**（App 菜单挂载规则）  
→ 最可能原因：App 上级菜单选了系统根，没有选 App 目录

### 场景 3：「大屏预览页面空白」

→ 手册二 **第十章 10.3**（预览 URL 格式）  
→ 最可能原因：开发环境 URL 没有带 **`isDev=1`** 参数

### 场景 4：「新建用户/角色/组织时报 500 或 D5001」

→ 手册一 **第七章**（踩坑汇总）  
→ 最可能原因：NOT NULL 字段收到 NULL 值

### 场景 5：「数据源连接测试失败」

→ 手册二 **第六章 6.3–6.4**（连接配置 + 排查）  
→ 最可能原因：连接字符串格式错误（须用 **JDBC 模板**，非 ADO.NET 写法）

### 场景 6：「Web 和手机端数据不同步」

→ 手册三 **第六章 6.5**（不同步排查）  
→ 实际上不应发生（同表）；检查是否操作了不同的功能设计

### 场景 7：「某个字段/配置不知道填什么」

→ 查对应手册的 **附录 A**（配置字典）  
→ 附录中有枚举值、格式要求、错误码说明

## 启动顺序

1. Redis（`docker start jnpf-redis`）
2. Flowable 桩（`node flowable-mock-server.js`）
3. 后端 API（`dotnet run --project application/JNPF.API.Entry/JNPF.API.Entry.csproj`）
4. 主 WEB / 大屏 / 报表（各自 `dev` 命令）
5. UniApp（`uniapp-h5-proxy.js` 或 HBuilderX）

详细环境配置见各手册 **第二章**。
