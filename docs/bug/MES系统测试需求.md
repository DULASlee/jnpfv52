# 原始需求说明书：某机械制造企业 MES 系统

## 1. 系统名称和所属行业
- **系统名称**：某机械制造企业 MES 系统
- **所属行业**：制造业 / 机械加工

## 2. 核心业务对象
- 工单
- 物料
- 工序
- 工艺路线
- 设备
- 模具
- 治具
- 质检单
- 不良品
- 人员
- 仓库

## 3. 使用角色及职责
- **车间主任**：负责生产排程、工单下发、插单处理、监控整体生产进度。
- **调度员**：根据订单生成生产工单，按设备负荷自动排产，将工单推送到对应机台。
- **操作工**：接收工单、上机加工、报工、设备点检。
- **质检员**：执行首检、巡检和终检，填写质检报告，判定不良品责任归属。
- **仓库管理员**：负责生产物料的配套配送、半成品流转、成品入库。
- **设备管理员**：负责设备台账维护、维修记录登记及保养计划执行。
- **管理层**：查看各类生产报表。

## 4. 核心业务流程
1. **排程与下发**：调度员先根据订单生成生产工单，系统按设备负荷自动排产，然后将工单推送到对应机台的平板端。
2. **物料配送**：仓库管理员根据工单进行齐套性检查，接着将物料配送至指定工位，然后操作工扫码确认收料。
3. **加工与报工**：操作工在平板端接收工单后，扫描物料批次号上机加工。每完成一道工序，系统自动记录工时、设备号及产量。
4. **质检流转**：操作工发起质检请求后，质检员在终端收到任务，接着进行现场判定。首检通过后方可批量生产；终检通过后，批次流转至下一道工序或入库。
5. **异常处理**：产生不良品时，质检员先发起不良品处理单，然后由工艺工程师判定是报废、返修还是让步接收。
6. **入库**：成品经终检合格后，系统生成入库单，库存数据增加。
