### T12 违规详情

**文件 1**: `SqlSugarConfigureExtensions.cs:217`
```csharp
var tenantId = httpContextAccessor?.HttpContext?.User?.FindFirst("TenantId")?.Value
    ?? httpContextAccessor?.HttpContext?.User?.FindFirst("tenant_id")?.Value;
```
- 绕过 TenantResolver，自行解析 JWT
- 无防越权校验（IsAdministrator 检查）
- 租户信息用于 SqlSugar 数据库切换，影响全局

**文件 2**: `KeyVariable.cs:71`
```csharp
string tenantId = httpContext?.User.FindFirst("TenantId")?.Value;
```
- 同上，直接读 Claim
- 用于系统变量解析，可能影响系统配置

**修复**: 两处替换为 `TenantResolver.Resolve().ToString()`
