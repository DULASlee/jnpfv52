## 一、启动系统

### 1. 启动后端

打开终端 1：

```
cd d:\JNPF-v52\backend
dotnet run --project application/JNPF.API.Entry/JNPF.API.Entry.csproj
```

等待输出 `Now listening on: http://localhost:5000`（**冷启动**约 60–90 秒；热启动约 10–30 秒）。启动过程中的 `MemoryCache NullReferenceException` 不影响功能，忽略。

<!-- 实测修正：二次启动明显快于 90s，保留冷启动上限 -->

验证：浏览器访问 `http://localhost:5000/newapi`，看到 API 文档页面 → ✅

### 2. 启动 PC 前端

打开终端 2：

```
cd d:\JNPF-v52\jnpf-web-vue3
pnpm run dev
```

约 5 秒后访问 `http://localhost:3100/`。

### 3. 启动大屏前端

打开终端 3：

```
cd d:\JNPF-v52\jnpf-web-datascreen
pnpm run dev
```

约 30 秒后 Vite 就绪（**勿单独在浏览器打开 8100 登录**；大屏无独立登录页，须从 PC 端菜单进入，见第五节）。

### 4. 启动移动端

**前提**：已用 HBuilderX 对 `jnpf-app-vue3` 执行过 **发行 → 网站-H5**，存在目录 `unpackage/dist/build/web/`（含 `index.html`）。若无，先发行再执行下列命令。

```
cd d:\JNPF-v52\jnpf-app-vue3
python scripts/proxy_server.py
```

<!-- 实测修正：原路径 unpackage/.../web 下无 proxy_server.py；脚本在 jnpf-app-vue3/scripts/，API 转发至 localhost:5000 -->

终端输出应含 `H5 proxy: http://localhost:3800/`。访问 `http://localhost:3800/`，F12 → 设备模拟 → 选 iPhone 12 Pro。

### 5. 登录验证

| 系统 | 如何认证 | 登录后看到 |
|------|----------|------------|
| PC（`localhost:3100`） | 页面输入 **admin / 123456** | 首页仪表盘，左侧菜单含「在线开发」 |
| 大屏（`:8100/DataV/`） | **无独立登录页**；须先在 PC 端登录，再从「在线开发 → 大屏设计」进入（跳转 URL 自动带 token） | 左侧导航：大屏管理、大屏分类、数据源管理等 |
| 移动端（`localhost:3800`） | 页面输入 **admin / 123456** | 底部 5 个 Tab：首页、协同、应用、消息、我的 |

## 二、亮点一：Web 表单零代码

### 话术

> 接下来演示平台的核心能力——低代码开发。传统开发一个新功能需要前后端配合至少 2-3 天，我们拖拽方式 10 分钟完成。

### 步骤 1：进入功能设计

点左侧菜单 **「在线开发」**（展开子菜单）→ 再点 **「功能设计」**。地址栏应变为 `.../onlineDev/webDesign`，页面有搜索栏和 **「新建」** 按钮。

<!-- 实测修正：仅点父级不跳转；若出现「无权访问」回到 §0 配权限 -->

若仍停留首页或提示无权：F5 刷新后重试；或检查 §0 第 4–5 项。

### 步骤 2：新建功能

点「新建」→ 在弹窗中先点 **「表单」**（另一项为「视图」）→ 进入三步向导。

**基础设置**页填写后点「下一步」：

| 字段 | 填什么 |
|------|--------|
| 功能名称 | 客户信息管理 |
| 功能编码 | customerdemo（**仅英文/数字/小数点，不能用下划线**；勿与已有 `customer` 冲突） |
| 功能分类 | **必选**（下拉选一项，否则无法下一步） |
| 数据表 | 不点「新增」即自动建表（无单独「数据库表」输入框） |

<!-- 实测修正 2026-05-28：原写法「点新建直接填三字段」；实际须先选表单类型，且为向导非单对话框 -->
<!-- 实测修正 2026-05-28：原写法 customer_demo；编码校验拒绝下划线，改为 customerdemo -->
<!-- 实测修正：库中已有功能编码 customer、菜单 model/customer；沿用旧数据可走 customer，但须在角色权限中授权且菜单勾选可见 -->

> 确定后进入 3 步设计向导：基础设置 → 表单设计 → 列表设计。

### 步骤 3：设计表单

点顶部步骤栏「表单设计」进入设计器：

- 左侧面板：控件列表（基础控件、高级控件等分类）
- 中间区域：表单画布
- 右侧面板：属性配置（选中组件后才显示）

**拖拽 5 个组件**：

| # | 左侧找 | 右侧属性面板配置 |
|---|--------|-----|
| 1 | 基础控件 → **单行输入** | 标签=「客户名称」，字段名=「customer_name」，勾选「必填」 |
| 2 | 基础控件 → 单行输入 | 标签=「联系人」，字段名=「contact_person」 |
| 3 | 基础控件 → 单行输入 | 标签=「联系电话」，字段名=「phone」 |
| 4 | 基础控件 → **下拉选择** | 标签=「客户类型」，字段名=「customer_type」。选项添加：企业、个人、政府 |
| 5 | 基础控件 → **多行输入** | 标签=「地址」，字段名=「address」 |

<!-- 实测修正 2026-05-28：原写法「下拉选择器」「多行文本」；设计器左侧名称为「下拉选择」「多行输入」 -->

点顶部「保存」。

> 拖拽后必须**点击画布上的组件**，右侧属性面板才会显示。

### 步骤 4：设计列表

点顶部步骤栏 **「3 列表设计」**（或步骤条「列表设计」）。从左侧字段列表勾选（客户名称、联系人、联系电话、客户类型、创建时间）拖到右侧已选列区域。将「客户名称」「客户类型」设为可搜索。点顶部「保存」。

<!-- 实测修正 2026-05-28：须先在表单设计步骤点「保存」，再进列表设计保存，最后关闭向导；仅点「取消」不会出现在功能设计列表 -->

### 步骤 5：发布

向导内表单、列表均「保存」并关闭后，回到功能设计列表页，在「客户信息管理」行点操作列的「发布」→ 确认。如弹窗有 PC 端/移动端勾选项，两项都勾选。提示「发布成功」→ ✅。

<!-- 实测修正 2026-05-28：未完成向导保存时列表仍为「暂无数据」，无法执行本步 -->

> 如报 COM1013：表单未保存 → 回设计器保存。如报 COM1014：列表未保存 → 切到列表设计保存。

### 步骤 6：配置菜单

点「系统管理」→「菜单管理」→「新增」。填写：菜单名称「客户信息管理」、上级菜单选「在线开发」、路由地址关联到 **customerdemo**（与步骤 2 功能编码一致）、**分类同时勾选 Web 与 App**（库中已有 `customer` 菜单若仅 Web，移动端看不到）。保存后 **F5** 刷新 PC 与移动端。

<!-- 实测修正 2026-05-28：库中 customer 菜单 F_CATEGORY=Web，未勾 App 时移动端「应用」Tab 无「客户信息管理」 -->
<!-- 实测修正 2026-05-28：未授权或未挂菜单时直链 /model/customer 提示无权访问 -->

### 步骤 7：验证 CRUD

| # | 操作 | 预期 |
|---|------|------|
| 1 | 刷新（F5） | 左侧菜单出现「客户信息管理」 |
| 2 | 点击进入 | 列表页面，暂无数据 |
| 3 | 点「新增」 | 弹出表单 |
| 4 | 填：阿里巴巴 / 张三 / 13800138001 / 企业 / 杭州 | — |
| 5 | 保存 | 列表出现记录 |
| 6 | 点操作列「编辑」 | 改联系人为「张三丰」，保存 |
| 7 | 点操作列「删除」 | 确认后记录消失 |

> **话术**：「一个增删改查业务功能，从零到可用只用了几分钟。系统自动建表、生成后端 API、渲染前端页面，全程零代码。」

## 三、亮点二：数字大屏零代码

### 话术

> 接下来演示数字大屏设计能力。企业日常经营需要数据看板做决策支撑，传统方式需前端专门开发，现在拖拽就能做。

### 演示顺序（推荐，全程在 PC 端完成）

| 顺序 | 操作 | 说明 |
|------|------|------|
| 1 | PC 端 `http://localhost:3100/` 登录 **admin / 123456** | 获取 OAuth token |
| 2 | 左侧「在线开发」→「大屏设计」 | **从这里进大屏**；跳转 `:8100` 时 URL 自动带 token，不会出现「登录过期」 |
| 3 | 在大屏管理页新建大屏 | 设计器正常打开 |
| 4 | 设计完成后保存、发布 | — |
| 5 | 回到 PC「在线开发」→「大屏设计」刷新列表 | 看到新建的大屏 |
| 6 | 点击大屏 → 全屏渲染 | 向客户展示效果 |

> **不要**在演示中单独新开标签访问 `http://localhost:8100/DataV/` 并尝试输入账号密码——大屏前端**没有**独立登录页，裸开会提示登录过期。

### 步骤 1：进入大屏管理

在 **已登录的 PC 端** 点击「在线开发」→「大屏设计」。浏览器会打开大屏设计入口（开发环境为 `http://localhost:8100/DataV/`，携带 token）。左侧深色导航栏：大屏管理、大屏分类、数据源管理、组件库、全局变量、数据集管理、静态资源、地图管理、工具箱。

### 步骤 2：新建大屏

在 **「大屏管理」** 页（左侧第一项）点 **「创建大屏」** → 填写大屏名称（如「业务数据总览」）、分组、尺寸 → 确定进入设计器。

<!-- 实测修正 2026-05-28：原写法「大屏分类→分组下+→新增屏幕」；v5.2 实测入口为「大屏管理」页的「创建大屏」弹窗。「大屏分类」页为「创建分类」+模板区 -->

### 步骤 3：设计大屏

设计器布局：左侧=组件面板、中间=画布（1920×1080，深色背景）、右侧=属性/数据面板（含「属性」「数据」两个 Tab）。

**a. 添加标题：** 左侧「文本」→ 拖「文本」组件到画布顶部。右侧属性面板修改内容为「JNPF 业务数据总览」，字号 32，颜色白色。

**b. 添加柱状图：** 左侧「图表」→ 拖「柱状图」到画布左侧。选中组件 → 右侧点「数据」Tab → 数据类型选「静态数据」→ 粘贴（**柱状图必须用 categories + series，不要用 name/value 数组**）：

```json
{"categories":["1月","2月","3月","4月","5月","6月"],"series":[{"name":"业务量","data":[100,200,150,300,250,180]}]}
```

<!-- 实测修正 2026-05-28：源码 bar 组件读取 optionData.categories / series；name/value 与 x/y 数组均无法渲染柱状图 -->

右侧属性面板标题改为「月度业务量」。

**c. 添加饼图：** 左侧「图表」→ 拖「饼图」到画布右侧。数据 Tab 粘贴：

```json
[{"name":"企业","value":60},{"name":"个人","value":30},{"name":"政府","value":10}]
```

<!-- 实测修正 2026-05-28：饼图静态数据固定 name/value 数组（与柱状图格式不同，勿混用） -->

标题改为「客户类型分布」。

**d. 添加翻牌器（可选）：** 左侧「图表」→ 拖「翻牌器」到画布上方中间。右侧属性面板：数值=12580，标题=总客户数。

### 步骤 4：保存、发布、预览

点顶部工具栏「保存」→ 点「发布」→ 确认 → 点「预览」查看全屏效果。

### 步骤 5：PC 端跨端验证

回到 PC 端 `http://localhost:3100/`（保持登录态）→「在线开发」→「大屏设计」。列表中出现「业务数据总览」后，点击即全屏渲染大屏。

> 如果列表看不到：在同一 PC 会话中再次从「大屏设计」进入管理页，在设计器内点「预览」；或将预览 URL（含 token）发给客户浏览器打开。

> **话术**：「大屏发布后自动注册到菜单系统中，可投放到会议室大屏幕，也可生成独立链接分享。」

## 四、亮点三：移动端零代码

### 话术

> 移动端和 PC 端共用同一套后端和数据库，同一个账号多端登录。一次设计，PC 和移动端自动适配，数据实时互通。传统模式下这套移动端至少需要一个前端工程师工作两周。

### 步骤 1：确认移动端就绪

打开 `http://localhost:3800/`，F12 设备模拟选 iPhone 12 Pro。admin / 123456 登录。看到底部 5 个 Tab：首页、协同、应用、消息、我的。

### 步骤 2：进入应用菜单

点底部 **「应用」** Tab（从左数 **第 3 个**：首页、协同、**应用**、消息、我的）。地址栏为 `.../pages/index/apply`。看到「功能演示 / 常用菜单」等分组（从后端菜单同步；无数据时显示「暂无数据」）。

### 步骤 3：找到「客户信息管理」

在应用列表中找到「在线开发」分组 → 点开展示子菜单 → 看到「客户信息管理」入口。

> 如果看不到：回 PC 端 → 菜单管理 → 编辑「客户信息管理」→ **分类须勾选 App（建议 Web+App 都勾）** → 保存 → 移动端下拉刷新。须先完成亮点一发布并配置菜单。

<!-- 实测修正 2026-05-28：未配置 App 分类时「应用」Tab 仅有功能演示/常用菜单，无「客户信息管理」 -->

### 步骤 4：移动端 CRUD

点「客户信息管理」进入列表页。点顶部「新增」按钮（或右下角「+」按钮）打开表单。填写：腾讯科技 / 李四 / 13900139000 / 企业 / 深圳。点「保存」，列表出现「腾讯科技」。
