### 务实设计决策（避免维护成本过高）

| 决策 | 理由 |
|------|------|
| etcd → 数据库 route_table | etcd 代码为零、本地无集群、单实例架构用不到 Raft；route_table 已有完整 DDL+实体+读写 |
| OTel 零 NuGet | 用 BCL `System.Diagnostics.ActivitySource`（.NET 8 内置 OTel 桥接），InteAssistant 不加包 |
| 心跳无独立服务 | 复用 EnsureRouteAsync 写 LastHeartbeat，等真正多实例时再加独立心跳 HostedService |
| Worker 恢复复用 Quartz 骨架 | DisallowConcurrentExecution + DistributedLock 模式与 StaleMonitorService 一致 |
